# Android 原生工程

本目录用于正式维护并交付 Android 原生应用源码，建议使用 Kotlin、Jetpack Compose，并嵌入共享 RN 设备模块。

当前仅建立目录和职责说明，尚未创建 Gradle 应用工程，也未迁入设备 SDK 或配网实现。

职责包括全局导航、账号、首页设备列表及快捷开关、添加设备、扫码、BLE/Wi-Fi 配网、我的、房间与设置，以及设备通信、权限、安全存储、升级任务、RN 容器及资源包管理。

RN 页面包括设备控制、更多、设备内分享、定时及固件升级；这些页面调用原生服务，不独立持有登录态和设备连接。

本目录是长期维护的宿主源码，必须纳入 Git；不存放 Expo 自动生成工程，不执行 `expo prebuild --clean`。

详见 [混合架构重构方案](../docs/SDD/2026-11-01-原生与RN混合架构重构方案.md)。
