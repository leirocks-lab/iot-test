# ROWAN App 业务规范

这里将已给定资料整理为可索引、可追溯、可迭代的 SDD 输入。当前有 59 个功能规范、111 个 Excel 条目、45 个范围内关联 API；中文命名迁移后初版功能版本为 0.1.1、draft、unplanned；后续版本与交付状态以功能索引为准。

## 入口

- [功能索引](<功能索引.md>)：按业务层级、API 和原始条目定位功能。
- [范围覆盖](<来源资料/范围覆盖.md>)：确认每个原始条目的唯一主归属。
- [来源登记](<来源资料/来源登记.yaml>) 与 [Excel 范围快照](<来源资料/范围快照.yaml>)：追踪资料版本、行号和 SHA-256。
- [资料冲突](<来源资料/待确认事项.md>)：实现前需要确认的字段及交互。
- [首页问询](<迭代变更/变更-20261007-004/需求问询.md>) 与 [其余业务问询](<迭代变更/变更-20261007-005/需求问询.md>)：追踪所有业务的建议和用户确认/批量授权采纳依据；[本轮技术待确认](<迭代变更/变更-20261007-005/技术待确认.md>) 保存剩余业务接口缺口快照。
- [管理约定](<规范管理/管理约定.md>)、[业务术语](<规范管理/业务术语.md>)、[公共规则](<公共规则/业务规则.md>)。

## 唯一功能边界

[补充 API 及开发人员的 Excel](<../docs/智能家居物联网项目计划&需求范围（补充API关联及开发人员）.xlsx>) 是唯一范围依据。Word V1.4、UI 和流程图不能新增功能。Excel 明确的 Store 占位、Mine 未冻结页面、首页布局后续定义均保留边界，不能借占位扩展业务。

Word 的 70 个接口没有全部纳入：仅收录 Excel API 关联列引用的 45 个。UI 目录整体登记哈希用于资料追踪，登记不代表其中所有页面都纳入开发。

当前应用为根目录单一 Expo/CNG 项目（CHG-20261007-003），README 说明工程仅提供底座，未包含正式登录、配网、MQTT、OTA 或设备控制；规范整理不代表业务交付；单项目工程迁移及其检查证据见 [CHG-20261007-003](<迭代变更/变更-20261007-003/任务清单.md>)。

## 目录

`业务功能/<业务域>/<功能组>/<功能>/功能规范.md` 是功能主规范，旁边的 版本记录.md 保存版本摘要。无功能组时允许少一层目录。

- 规范管理：编号、版本、状态、术语。
- 来源资料：原始资料登记、唯一范围快照、覆盖和待确认事项。
- 公共规则：公共业务规则及范围内 API 契约。
- 迭代变更：每次迭代的变更提案、实施计划、任务清单。
- 发布基线：实际 App 发布采用的功能版本与规范 Git 提交。
- 规范模板：新增功能、变更和发布所用模板。
- 维护工具：规范维护与回归测试脚本。

例如：`业务功能/公共启动与账号/登录认证/验证码登录/功能规范.md`。目录及文件名称使用中文，RF/REQ/CHG 等稳定编号、API 标识和 YAML 字段保留原值。

## 维护命令

在仓库根目录安装已有项目依赖后运行，Node.js 版本沿用项目要求：

```bash
pnpm specs:index
pnpm specs:check
pnpm specs:search RF-0020
pnpm specs:search REQ-094
pnpm specs:search /api/app/session
pnpm specs:test
```

功能索引.md 由规范元数据生成。业务域和功能组目录分别与 domain_title、group_title 保持一致；移动功能目录后同步中文层级及相对引用，再重新生成索引，稳定 ID 不变。范围覆盖.md 与功能索引.md 同时生成，不作为日常功能信息维护入口。

## SDD 迭代

1. 从索引定位功能，阅读 spec、依赖、原始条目及未解决冲突。
2. 复制变更模板建立 `迭代变更/变更-YYYYMMDD-NNN/`，记录对应 CHG-YYYYMMDD-NNN 编号。范围外功能必须先获得明确范围变更，不直接追加开发任务。
3. 变更提案写需求差异；实施计划冻结技术方案和接口；任务清单引用 RF 编号及 AC 编号。
4. 范围内变更评审后更新功能规范、版本及版本记录。规范批准与功能验收、发布分别记录。
5. 实现并保存平台、输入、结果和测试证据；重新生成索引并执行校验。
6. 实际发布时使用 release 模板填写版本、已提交的完整规范 SHA 和已验收功能；历史基线从指定 Git 提交读取，不能按当前文件解释旧发布。

## 初次整理的限制

来源内容保持原样，Excel API 动作与编号冲突单独记录。工作簿未声明版本，登记为 null，不编造 V1；UI、流程图同理。日期使用本次收集日 2026-10-07。

本轮没有业务批准、应用发布或生产基线；发布基线目录仅提供操作说明和模板。原始资料当前未被 Git 跟踪，创建真实发布基线前须确保必要资料与规范已提交且可恢复。
