# 业务术语

| 术语 | 本批含义 | 依据 |
| --- | --- | --- |
| ROWAN | 公共 App 与服务底座名称 | Word §2 |
| AS / Antarctic Star | UI 来源子品牌，不改变公共身份体系 | Word §2 |
| 设备绑定 | 云端用户与设备建立关系；不同于 Wi-Fi 连接成功 | REQ-041、054～058 |
| sa / mbr / obs | 管理员 / 普通成员 / 观察员；权限由云端确认 | PAIR-05、MORE-01 |
| 房间 / location | 用户组织设备的房间归属，沿用 API location 命名 | REQ-085、097～103 |
| 配网 | 原生/蓝牙、Wi-Fi、认证、激活与绑定过程 | REQ-049～056 |
| property/set | 设置期望属性，不能立即认为设备已经执行 | REQ-061～067 |
| property/update | 设备真实属性与控制结果回报 | REQ-070 |
| service/call | 清洁重置等一次性服务调用 | REQ-069 |
| MCU / Wi-Fi OTA | 两类固件版本检查及云端升级任务 | REQ-091～095 |
| 一次定时 / 周期日程 | type=once / periodic；云端按时区执行 | REQ-075～083 |
| 温度单位 / 度量制式 | C/F 与 metric/imperial，不等同于产品协议单位 | REQ-110、111 |
| spec / change / release | 当前功能规范 / 一次迭代执行记录 / App 发布基线 | 管理约定 |
| 全屋 | 首页跨房间的设备总览页签；首次默认选中，已记忆页签失效时回退到此页签 | 首页 UI；CHG-20261007-004 Q1 用户确认 |
| 首页快速开关等待态 | 已发出设备控制请求但尚无匹配结果回报；显示等待且禁用该设备开关，不等同于控制成功 | REQ-029；CHG-20261007-004 Q3 用户确认 |
| 首页批量删除 | 逐台解绑当前用户与设备的关系；成功和失败分开汇总，失败项保持选中，不表示物理设备被删除 | REQ-032；CHG-20261007-004 Q4 用户确认 |
| 确认值 | 已由真实服务端响应或有效设备回报确认的状态；缓存的确认值不等于当前实时在线状态 | CHG-20261007-005 业务问询与用户批量授权 |
| 结果未知 | 请求发出后未获得足以确定最终结果的证据，不能据此认定成功、失败或可安全重复执行 | CHG-20261007-005 业务问询与用户批量授权 |
| 添加上下文 | 当前账号正在处理的一次设备添加；配网、绑定确认、昵称及完成结果均属于该上下文，结果未知时重新进入流程先核对 | REQ-036、054～058；CHG-20261009-001 Q2用户确认，沿用既有单活跃上下文规则 |
| 绑定结果核对 | 对已提交但结果未知的事务获取现有绑定证据；不重新发送Wi-Fi凭据或再次消耗绑定码 | CHG-20261007-005添加设备问询；CHG-20261009-001 Q2用户确认 |

术语与 API 字段允许业务中文和历史命名同时存在；不要为统一术语擅自改 wire 字段。

## 本轮模拟通信术语

- Mock适配器：依据文档模拟通信对端，通过真实业务服务驱动流程，不证明生产服务已上线。
- Shadow确认值：来自reported的实际模拟设备状态；desired和accepted不代表执行完成。
- 模拟验收：明确标注模拟环境的运行证据；与真实硬件、后端及发布验收分别记录。
