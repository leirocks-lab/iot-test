# 公共 API 约定

依据 SRC-PRODUCT-001 第 6 章，仅适用于 Excel 范围内接口；接口设计不代表后端已经实现。

## 环境与请求头

实际域名待部署确认，不能把示例域名当作生产地址。

| 环境 | Base URL 表示 | 用途 |
| --- | --- | --- |
| 开发 | ${ROWAN_APP_API_BASE_URL_DEV} | 开发联调 |
| 测试 | ${ROWAN_APP_API_BASE_URL_TEST} | 系统测试和回归 |
| 生产 | ${ROWAN_APP_API_BASE_URL} | 正式 App |

| Header | 必填 | 示例 | 说明 |
| --- | --- | --- | --- |
| Authorization | 条件必填 | Bearer ${accessToken} | 需要登录态的接口必须传。 |
| Accept-Language | 否 | zh-CN | zh-CN / zh-TW / en。 |
| Content-Type | 条件必填 | application/json | 有 JSON Body 时必填。 |
| X-Request-Id | 建议 | req_01J0ROWAN0001 | 链路追踪标识。 |

## 公共响应与错误

```json
{"code":0,"message":"获取成功","success":true,"data":{}}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| code | Integer | 0 表示成功，非 0 表示失败。 |
| message | String | 面向客户端的本地化响应消息。 |
| success | Boolean | 请求是否成功。 |
| data | Object/Array | 具体业务数据；无数据时可省略或返回空对象。 |

| HTTP/业务码 | 含义 | App 处理 |
| --- | --- | --- |
| 400 | 参数错误 | 按字段提示修正输入，不自动重试。 |
| 401 | Token 无效或过期 | 尝试刷新 Token；失败则回登录页。 |
| 403 | 无资源或设备权限 | 关闭控制并刷新设备/成员关系。 |
| 404 | 资源不存在 | 刷新列表并移除失效数据。 |
| 409 | 状态冲突或重复数据 | 刷新最新状态后提示用户。 |
| 429 | 请求过于频繁 | 按 Retry-After 退避。 |
| 500 | 服务端异常 | 展示通用错误并保留 X-Request-Id。 |

第 8 章部分示例省略公共外壳，不据此改动已定义的响应约定。具体冲突应另行登记。

## 字段与时间

- 保留 deviceID、deviceId、productID、taskID、firmwareID 等原契约拼写；不统一改名。
- 服务端时间使用 UTC ISO-8601；日程另保存 IANA timeZone。
- Idempotency-Key 是文档建议，不是已经确认的全接口强制字段。
- REST 成功不等于设备执行；控制依赖 MQTT，固件升级依赖任务结果。
- 范围内接口参数、响应、错误和来源表号见 [契约快照](<接口契约.yaml>)。
