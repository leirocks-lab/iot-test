# 公共业务规则

## 范围与资料优先级

1. 用户确认的功能范围变更。
2. SRC-SCOPE-001 Excel 中的 111 个条目及其明确边界。
3. Word、UI、流程图仅用于补充上述功能。相互矛盾时记录冲突，不能自行扩展范围。

Word 里的广告、第三方登录、个人资料编辑、注销、用户反馈、全局帮助、联系人、产品说明书及 RN 插件不进入本批功能。APP-01 只用于启动配置，THING-01 只服务范围内产品模式和日程动作校验；它们不授权额外功能。

## 云端与设备控制

依据 Word §4、§9 和 Excel 对应条目：账号、持久化元数据、房间、共享关系、OTA 任务、定时和用户设置走 REST；即时控制与实时状态走 MQTT。

| 类型 | Topic | 方向 | 用途 |
| --- | --- | --- | --- |
| 属性查询 | thing/{deviceID}/property/get | App → 设备/云 | 进入设备页后请求完整属性。 |
| 属性设置 | thing/{deviceID}/property/set | App → 设备 | 下发开关、目标温度、模式等期望值。 |
| 属性上报 | thing/{deviceID}/property/update | 设备 → App/云 | 上报实时状态和控制结果。 |
| 服务调用 | thing/{deviceID}/service/{serviceIdentifier}/call | App/云 → 设备 | 执行清洁重置等一次性动作。 |
| 事件上报 | thing/{deviceID}/event/{eventIdentifier}/post | 设备 → App/云 | 故障、告警和状态事件。 |

- 下发时进入发送中，收到上报后更新确认状态；超时或离线恢复最近确认状态。
- 重连时更新过期凭证、恢复订阅并执行全量 property/get。
- 产品属性标识、模式、取值范围和服务必须按产品能力确认。文档示例不是完整产品物模型。
- 房间和设备操作以云端权限为准；不要用 App 按钮隐藏替代后端鉴权。

## 品牌、语言与数据

Word §2.2 的 brandId 用于确有差异的协议及产品目录筛选，不拆分账号、设备、房间、分享、OTA、日程或 MQTT Topic。

- 本批语言仅 zh-CN、zh-TW、en；其他语言不纳入。
- 密码、Wi-Fi 密码、Token 和 MQTT 凭证不进入普通日志或无关接口。
- 用户设置未传字段保持原值；temperatureUnit 与 measurementSystem 的一致性规则待确认。
- Store 是占位；Mine 仅包含范围内退出与偏好入口。UI 里额外入口不开发。
- 云端日程负责时间、时区与到点执行；不依赖 App 保持在线。
