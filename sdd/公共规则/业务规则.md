# 公共业务规则

## 范围与资料优先级

1. 用户确认的功能范围变更。
2. SRC-SCOPE-001 Excel 中的 111 个条目及其明确边界。
3. Word、UI、流程图仅用于补充上述功能。相互矛盾时记录冲突，不能自行扩展范围。

Word 里的广告、第三方登录、个人资料编辑、注销、用户反馈、全局帮助、联系人、产品说明书及 RN 插件不进入本批功能。APP-01 只用于启动配置，THING-01 只服务范围内产品模式和日程动作校验；它们不授权额外功能。

## 云端与设备控制

依据 Word §4、§9 和 Excel 对应条目：账号、持久化元数据、房间、共享关系、OTA 任务、定时和用户设置走 REST；即时控制与实时状态走 MQTT。

本轮依据 CHG-20261024-001 与 V1.6 第10章，真实MQTT统一使用Classic Shadow；旧版property/service/event路径不再是本轮真实契约。Excel中相应既有能力的传输文字已经用户明确授权纠正。

| 类型 | Topic | App职责 |
| --- | --- | --- |
| 查询 | $aws/things/{deviceID}/shadow/get | 四响应订阅确认后发布零字节消息；读取影子快照 |
| 更新 | $aws/things/{deviceID}/shadow/update | 发布state.desired；产品字段大小写按原字典 |
| 查询结果 | $aws/things/{deviceID}/shadow/get/accepted、get/rejected | 读取reported或处理404等失败 |
| 更新结果 | $aws/things/{deviceID}/shadow/update/accepted、update/rejected | 区分desired接受与设备reported；处理拒绝/冲突 |

- 四个响应精确订阅，不另订阅update/delta，不用shadow/#；deviceID为会话接口确认的thingName/thingRef。
- 设备reported的clientToken不要求等于App控制token；云接受之后的新reported和目标属性才是确认依据。部分字段合并、旧版本过滤、超时/离线保持最近确认值，不自动重放。
- 一次性动作以原字段写desired，保留次数/清零/流水号语义；缺产品资料禁用，不能默认Mock字段。
- App不直接订阅connect、notice、callapi、mcu/version、mcu/ota；这些由设备/云端承担。告警保留既有设备页展示与明确恢复依据，云端读取契约缺失时待接入，不新增消息中心。
- 模型失败只允许明确配置的只读快照同步；不生成假模型，不开放控制。凭证有效期、自动退避和产品动作字段未确认时不猜测。
- 房间和设备权限以云端为准，UI隐藏不替代鉴权。

## 品牌、语言与数据

Word §2.2 的 brandId 用于确有差异的协议及产品目录筛选，不拆分账号、设备、房间、分享、OTA、日程或 MQTT Topic。

- 本批语言仅 zh-CN、zh-TW、en；其他语言不纳入。
- 密码、Wi-Fi 密码、Token 和 MQTT 凭证不进入普通日志或无关接口。
- 用户设置未传字段保持原值；temperatureUnit 与 measurementSystem 的一致性规则待确认。
- Store 是占位；Mine 仅包含范围内退出与偏好入口。UI 里额外入口不开发。
- 云端日程负责时间、时区与到点执行；不依赖 App 保持在线。

## CHG-20261007-006 模拟环境协议

本轮设备Mock采用固件V1.1 AWS Classic Shadow：$aws/things/{thingName}/shadow/get|update及显式accepted/rejected/delta；通过适配器映射已有通用属性/服务语义。此段仅记录历史Mock决策；本轮真实协议以CHG-20261024-001为准，产品字段与部署权限仍须实际核实。HTTP和设备全Mock为用户明确批准的开发目标，不关闭现有真实契约冲突。
