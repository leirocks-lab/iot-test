# CHG-20261021-003 实施计划

## 输入与边界

- 关联 RF-0001 基础框架搭建、REQ-001、RF-0001-AC-015。
- 依据用户 2026-10-21 明确视觉指令及 [变更提案](变更提案.md)。
- 依据 Expo SDK 57 `expo-splash-screen` 配置插件文档：`backgroundColor` 使用十六进制颜色，`image` 指定启动页图片，默认 `imageWidth` 为 100，原生启动页按 contain 方式居中。
- 仅修改启动页配置；不修改业务页面、API、品牌身份、状态栏或原生目录。

## 实现方案

1. 在 `app.config.ts` 的 `expo-splash-screen` 插件中将 `backgroundColor` 设置为 `#186DAF`。
2. 将 `image` 设置为 `./assets/images/logo-white.png`，移除旧启动图和显式宽度配置，使用 SDK 默认宽度并保持居中。
3. 通过 Expo config 解析确认插件配置和资源路径有效；通过 lint、typecheck 及规范检查验证。

## 接口与兼容

无 API、MQTT、物模型、数据结构或路由变化。CNG 原生工程若已生成需重新生成/构建；热更新不能替换原生启动页资源。回退方式为恢复原 `expo-splash-screen` 三项配置。

## 验证与交付

- 自动：`pnpm exec expo config --json` 检查 `expo-splash-screen` 配置；`pnpm lint`；`pnpm typecheck`；`pnpm specs:index`；`pnpm specs:check`。
- 真机：Android/iOS release 或等效构建冷启动，确认纯色背景、Logo 居中且使用白色 Logo；当前环境未连接真机时如实记录待验收。
