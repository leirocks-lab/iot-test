# CHG-20261014-004 实施计划

## 输入与边界

目标 RF-0044 / REQ-090，关联 MORE-05、RF-0022、AC-001～011；本轮技术目标以 [需求问询](需求问询.md) 最终确认及目标规范为准。仅当前设备文本帮助，基础 UI 沿用已有 Page/Card；无正式视觉稿，不新增业务入口。

## 实现方案

先更新目标规范，再修改业务代码。服务层向 MORE-05 传 `type=text`、deviceID、AbortSignal；真实适配按已登记数组契约验证帮助项，不将 URL 内容当正文执行。Mock 按用户/设备鉴权及语言返回数组，可测试空态、权限和失败。独立帮助读取状态管理加载、失败、重试、同设备内容保留与设备/账号切换清理；页面聚焦时读取、失焦时取消，迟到响应不覆盖当前设备。

## 接口与兼容

不新增 REST/MQTT/物模型接口。现有产品配网帮助 PAIR-07 保持原行为与测试；MORE-05 真实模式仍经配置的 HTTPS/租户适配器，不降级 Mock。Word 单对象字段表与示例数组差异以已登记真实快照核查，异常响应明确失败。`type=url` 仅记录待确认，不配置猜测域名。

## 验证与交付

测试正常列表、空数组/空正文、失败后保留同设备成功内容、1451/1452 权限结果、迟到响应、设备/账号切换、Mock/真实请求契约及 PAIR-07 回归。执行 lint、typecheck、Vitest、SDD 索引与检查、Android/iOS JS 导出；记录平台、输入、预期、实际和限制。真实接口、视觉与设备未就绪时保持 `draft / in_progress`，不标 verified/released。
