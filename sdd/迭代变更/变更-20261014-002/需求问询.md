# CHG-20261014-002 需求问询

## 已核实事实

- Home 当前将 Busy 渲染在 Page ScrollView 内容中，因此 ActivityIndicator 会参与卡片布局并造成加载时内容位置异常。
- Page 已支持 RefreshControl，但没有 ScrollView 外部加载区域插槽。
- 用户要求加载图标有独立区域，结束后回到加载前位置。

## 决策

1. Page 增加可选 `loadingContent` 插槽，位置在 header 与 ScrollView 之间。
2. Home 用 56dp 固定区域承载 Busy，loading 结束时移除区域。
3. 不引入第三方库，不改变请求和下拉刷新协议。

本次为已明确的布局修正；GrillMe 工具入口当前不可调用，未伪造问询结果。
