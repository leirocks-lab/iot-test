# CHG-20261007-001 整理实施计划

## 输入与边界

用户已确认的结构设计与 Excel 唯一边界。读取四组来源并保留原文、负责人、优先级和可定位编号。不改原始资料，不实施移动端功能，不创建虚假发布。

## 实现方案

1. 登记三个文件和 UI 目录的来源版本与哈希；提取 Excel 111 个条目为只读基线快照。
2. 合并支持同一可验收目标的页面状态/流程步骤，建立 59 份功能规范及版本记录。
3. 只归档 Excel 引用的 API 契约，链接 UI 与流程节点，集中登记冲突。
4. 提供变更、实施、验收及发布模板；生成按业务、API、条目的索引。
5. 校验范围覆盖、重复 ID、依赖、链接、版本与来源漂移，测试重命名及历史发布校验。

## 接口与兼容

不修改 App 公开接口。只添加 pnpm specs:index/check/search/test 和开发期 yaml 解析依赖。维护脚本使用 Node，依赖沿用项目安装；不需要 Python 来进行日常索引维护。

## 验证与交付

本轮验收限文档归档和工具。功能 spec 的业务 AC 仍待后续真机、后端、设备及产品评审。发布清单验证指定 Git 提交，不以当前规范代替旧基线。
