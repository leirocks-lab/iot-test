# CHG-20261012-003 找回密码前端交互

状态：in_progress

## 目标

细化 RF-0009（REQ-018～REQ-021）的找回密码页面：邮箱输入、邮箱验证、密码重置及成功返回登录。当前仅实现前端 Mock 交互，真实查询和验证码接口待联调。

## 规范差异

现有单页旧重置表单 → 三步流程：邮箱页使用 `find-password.png`；邮箱格式或 Mock 查询失败显示异常；验证页复用注册验证码交互且按钮文案为“下一步”；密码确认成功显示“新密码设置成功”并返回登录。

## 依据

用户于 2026-10-12 提供的四张页面截图及明确交互要求。GrillMe 副本在当前环境不可用，本次继续沿用已记录的跳过授权；不新增 API 契约。

## 待确认

真实账号查询接口、验证码发送/校验接口字段和错误映射待后续接口联调；Mock 当前以 `rowan@example.com` 作为已注册账号并使用现有验证码 `123456`。
