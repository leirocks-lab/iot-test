# CHG-20261009-001 认证入口首屏与登录注册分流

状态：in_progress

## 目标

首次进入账号入口时展示 ROWAN Logo、登录和注册两个操作。只有用户选择操作后才展示对应的账号输入表单；现有登录、注册、验证码和找回密码接口流程保持不变。

## 范围与依据

- RF-0002 启动与基础初始化（REQ-002）
- RF-0006 邮箱注册（REQ-009 至 REQ-014）
- RF-0007 邮箱密码登录（REQ-015）
- 用户指令（2026-10-09）：首屏展示 Logo，点击登录或注册后进入输入页面；样式先实现功能。

## 变更

- `/auth` 无 `mode` 参数时渲染入口页。
- `/auth?mode=login`、`register`、`reset` 继续渲染原有表单。
- 入口页的登录和注册操作通过既有 `mode` 路由进入表单，不新增认证接口。

## 约束与待确认

GrillMe 插件入口（AGENTS.md 指定路径）在当前环境不可用，已核对现有 Excel 范围、相关 RF 规范和实现后记录此限制。Logo 使用仓库现有 `assets/images/icon.png`，后续可替换为产品指定资源。真实 API 和 Android/iOS 业务验收仍按既有规范执行。
