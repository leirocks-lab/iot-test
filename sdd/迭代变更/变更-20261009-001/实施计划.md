## 实现方案

### 工作包 1：业务事务与结果

- 在 `src/services/` 新建添加设备业务编排，注入已有 RowanService、DeviceTransport 和可替换预算/时钟。公开明确阶段及各结果，便于 UI 同事接入。
- 先校验产品详情及输入，再按既有固件 Mock 路线处理握手和参数发送。沿用文档及 mock-v1 假设，不提升为生产协议。
- 二期地址继续 PAIR-04；绑定最终证据由 PAIR-05 获取，处理文档的 1121 进行中、1122 不存在、1123 过期。Mock 当前 404 不擅自等同真实进行中，若要调整 Mock 响应先记录差异与确认。
- 轮询间隔不低于 2 秒；Mock 默认沿用 3 秒及预算。确认成功、明确失败、离页或预算耗尽停止请求。对忽略 abort 的迟到响应也做轮次/账号检查；轮询不重发 Wi-Fi 或绑定。
- 未知结果保留事务标识，以查询核对；明确失败才提供对应可安全重试操作。真实 bindCode 生成/恢复契约仍待确认。
- 昵称保存与绑定分开；跳过不传空昵称；校验既有 0～20 字符边界。绑定已成功后只重试昵称、列表或会话，不重跑配网。
- 查询 HOME-01 确认新设备实际可见，再读取 DEVICE-01 凭证并尝试现有 ShadowSession；失败保留已绑定事实。会话生命周期归属现有 Runtime/页面边界，不临时创建无主连接。
- Wi-Fi 密码仅保存在当前添加上下文，失败/离页/结束按现有规则清理，不进入日志或普通存储；页面提供显隐和本地错误。

### 工作包 2：发现与页面生命周期

- 为扫描建立独立轮次、预算、AbortController；选择设备、离页、App进入后台和结束扫描均终止客户端扫描/监听。
- 以冻结的广播身份去重，忽略旧扫描轮次回调；同名不同身份保留两台，不凭广播名称认定产品支持。
- 由适配层解析已有协议和产品映射，再请求 PAIR-02 确认能力。正式广播缺少 productID 时保留适配缺口；Mock 注册表映射不扩散为页面硬编码。
- 扫描未发现与蓝牙关闭、权限拒绝分别呈现；保留既有手动/推荐入口及重试；支持先发现再选择产品。
- 真实网络检查/SSID 在能力适配边界实现；未知频段只提示 2.4GHz，未知 SSID 与未连Wi-Fi分别处理。生产手输SSID规则未冻结，Mock手填继续作为显式模拟输入。

### 工作包 3：扫码/相册

- 相机仅聚焦且前台时挂载，识别候选后暂停；相册按需选择图片并调用 SDK57 的 `Camera.scanFromURLAsync`，复用同一 codec。
- 预期需要 SDK兼容的 expo-image-picker；使用 Expo install 安装，不直接用包管理器 add。安装及 app.config 插件变化待进入该包再执行，并记录开发包重建需要。
- 多码图片去重后显式选择单候选，取消不绑定；格式错误、图片无二维码、权限不可再问均提供对应恢复动作。
- 仅解析版本化 Mock 协议；正式二维码格式待 C-005 冻结，不能把 product-only Mock 码当出厂绑定码。扫码分享原路径只复用，不扩展分享管理。
- 所有异步查询/绑定/选图结果检查当前轮次与账号，禁止离页后的导航或重复提交。扫码直接绑定与配网入口共用已绑定结果编排。

范围内 API：PAIR-02、PAIR-04～07、MORE-04、HOME-01、DEVICE-01；已有 PAIR-01 作为产品查找依赖。保持 wire 字段大小写，缺失事实在适配层显式失败。

## 验证与交付

每包执行与业务风险相关的单测：轮询成功/进行中/过期/总超时、取消及不合作的迟到驱动、双击和并发操作、用户切换、昵称失败、首页不可见和 MQTT失败；发现去重和旧回调；二维码无效/多码/重复识别。

随后执行 `pnpm lint`、`pnpm typecheck`、`pnpm test`、`pnpm specs:index`、`pnpm specs:check`。没有修改维护工具则无需新增工具测试。增加原生依赖时补 Expo Doctor、配置/平台bundle检查；实际结果写入任务清单，不以 bundle 代替设备运行。

平台运行级验收需要Android/iOS设备或已可运行的开发构建；真实配网需协议资料、硬件与后端。当前PowerShell可用命令检查未找到adb；iOS环境未确认。先完成可执行验证，分别记录平台未完成项，全部AC未通过前保持in_progress。新增原生模块及配置后，需要重新生成/构建开发包；本轮未手工修改android原生文件，已存在目录的同步尚待执行，不把JS导出当作新原生模块已在设备包中可用。

## 实际方案细化与限制

- AddDeviceFlow / QrScanFlow各自承担状态与操作，Runtime持有账号级协调器；重新进入页面保留未知事务，账号变化清除旧上下文。
- Provisioner支持传入HTTP绑定确认函数，旧协议测试调用仍可使用对端binding；应用流程只以PAIR-05为最终查询依据。
- Mock全流程预算为既有13项ACK预算、路由预算和绑定预算之和（155秒）；扫描30秒，绑定30秒/3秒间隔。数字仅为客户端Mock profile，真实时限未冻结。
- 临时Wi-Fi参数在Mock交换上下文结束时清理；业务快照不包含SSID密码、Token或bindCode；Mock云端已绑定记录保留用于结果查询，不是设备端取消。
- Expo系统选图不预先索取整库权限，相册扫码与相机共用版本化codec。真实HTTP模式拒绝rowan-mock-v1格式。
- expo-network只返回连接类型，未提供SSID/频段。本轮真实网络类型提示已接线；SSID读取和真实凭据能力仍未接入，真实配网入口明确不可用。Mock手输网络字段清楚标注。
- 客户端昵称采用去首尾空白、20码点上限，原有输入组件仍20字符限制；后端完整字符计数口径未冻结，不能据此宣称所有Unicode输入已满足生产契约。
- UI对接、示例操作及剩余任务见[UI对接说明](<UI对接说明.md>)、[任务与验收证据](<任务清单.md>)。

官方技术核查入口：[SDK57](https://docs.expo.dev/versions/v57.0.0/)、[Camera](https://docs.expo.dev/versions/v57.0.0/sdk/camera/)、[Expo 文档索引](https://docs.expo.dev/llms.txt)。具体 API 在修改前再次按对应版本页面和本地声明核对。
