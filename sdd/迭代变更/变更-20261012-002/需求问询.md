# 需求问询

## 范围

本变更细化 RF-0001 基础框架搭建中的可复用输入框组件能力，涉及现有输入框的前缀图标、可选清除操作和密码可见性切换。不新增业务模块、API 或持久化字段。

## 已核实事实及来源

- 当前 `src/ui/kit/Input.tsx` 仅包装 React Native `TextInput`。
- `Field` 和认证、地区、设备等页面复用该组件；现有 `secureTextEntry` 调用应保持兼容。
- 用户提供了 `input-clear.png`、`password-hidden.png`、`password-show.png`，并明确指定其用途。
- Expo 版本为 57，项目已使用 `expo-image`；图片资源可通过 React Native `ImageSourcePropType` 传入。
- 用户于 2026-10-12 明确指令：“跳过GrillMe继续执行需求”。该授权仅适用于本 CHG-20261012-002；本次未执行 GrillMe，原因和授权已记录。

## 决策树

### 第 1 轮：组件接口

1. 前缀图标：采用 `prefixIcon?: ImageSourcePropType`，调用方可传 `require(...)` 或 URI 图片 source；组件负责布局和渲染。
2. 清除能力：采用 `clearable?: boolean`；启用且当前有文本时显示指定清除图标，点击后调用 `onChangeText("")`，无值时隐藏。
3. 密码能力：沿用 `secureTextEntry`；密文显示 `password-hidden.png`，点击后显示明文并切换为 `password-show.png`，再次点击恢复密文。

## 用户最终共同理解

`Input` 提供可选前缀图片、可选一键清除和密码显隐切换；默认行为与现有 `TextInput` 保持兼容。密码和清除图标使用可访问的按钮区域，不改变受控值、输入回调或业务请求。

## 残余限制

- 本次不新增 SVG 解析器；SVG 图标由调用方以项目现有可渲染 source 形式提供，复杂 React SVG 组件不纳入该 prop。
- 未进行 Android/iOS 真机视觉验收；通过静态工程检查和现有测试验证。
