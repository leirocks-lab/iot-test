# CHG-20261012-002 实施计划

## 输入与边界

关联 RF-0001 0.4.0 → 0.5.0、REQ-001 及 RF-0001-AC-001、002、003。实现只在移动端 UI 组件层完成。

## 实现方案

1. 为 `Input` 增加 `prefixIcon`、`clearable` 属性，并使用统一图片容器布局。
2. 清除按钮只在可编辑、有文本且 `clearable` 开启时渲染，调用受控输入的 `onChangeText`。
3. 密码输入由内部 `passwordVisible` 状态控制实际 `secureTextEntry`，切换按钮使用指定资源。
4. 保留原始 `TextInputProps`、样式合并、placeholder 颜色和所有现有调用。
5. 文本区设置 `minWidth: 0` 并允许收缩，尾部清除/密码按钮区固定宽度且禁止收缩，避免两个图标把输入内容挤出容器。
6. 聚焦状态由外层容器绘制 1px `#CCCCCC` 边框，关闭原生输入的 Android 下划线和平台默认焦点描边。

## 接口与兼容

不涉及网络 API、存储或原生目录；新增属性均可选，旧调用无需迁移。
