# CHG-20261022-003 开发环境放行 HTTP 配网地址

状态：已确认开发测试边界；真实设备与云端验收待完成。

## 问题与目标

当前 PAIR-04 成功返回四个 HTTP 设备侧服务地址，真实配网在首个 BLE 写入前被两条协议的 HTTPS 校验拒绝。用户要求先支持 HTTP 测试，并明确仅 development 放行。目标是在该环境以 PAIR-04 原值推进实机流程，观察设备实际阶段与错误，不将此放行扩到 preview/production。

## 影响与待确认

App 真实编排的四地址预检查、运行环境传递及对应测试受影响。不能自动把 HTTP 改为 HTTPS；当前 IP 的 HTTPS 握手未成功。设备文档要求 HTTPS，HTTP 的固件/云端实际接受情况待联调。无发布基线，规范 draft / 交付 in_progress。

实机重试还暴露既有错误呈现遗漏：提交密码后若失败发生在进度状态建立前，`useAction` 保存错误、密码按现有安全规则清空，但 Wi-Fi 输入页没有渲染该错误，用户只看到页面闪回。该修复归属既有 RF-0020-AC-010/019，不改变密码清空规则或新增业务范围；先补规范和测试，再修 UI。
