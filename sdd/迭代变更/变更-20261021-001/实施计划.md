# CHG-20261021-001 实施计划

## 方案

新增 `src/components/add-device-provision.tsx`，拆分 Wi-Fi 表单、配网进度、昵称表单和房间抽屉。`src/screens/Add.tsx` 仅负责连接运行时状态与动作，继续调用 `AddDeviceFlow`。系统设置使用 Expo/React Native Linking；Android 优先 Wi-Fi intent，失败回退 `openSettings`，iOS 使用 `openSettings`。

## 兼容性

不新增依赖，不改变 API、配网协议、绑定轮询和账号上下文隔离。密码仅保留在当前页面状态并沿用离页清理。

## 验证

本次运行时缺陷先用项目安装的 React Native Web `View` 对实际 `Progress` 组件进行独立渲染，记录空错误字符串的原始警告；将条件改为显式返回 `Text` 或 `null`，复查空字符串、未传错误、正常错误文案与失败状态。此验证隔离图片、SVG 外壳，不替代完整路由操作或双平台实机验收。随后执行类型、lint 与 SDD 检查。

执行 `pnpm test`、`npx tsc --noEmit`、`npx expo lint`、`pnpm specs:index`、`pnpm specs:check`；Android/iOS 真机设置跳转与视觉需后续验收。
