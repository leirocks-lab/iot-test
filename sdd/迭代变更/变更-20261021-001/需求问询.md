# CHG-20261021-001 需求问询

日期：2026-10-21

## 已核实事实

- 本次用户明确报告 `Progress` 下空文本节点的 Web 错误，并指示“继续执行”。这是现有进度/失败页面的实现缺陷修复；无新增业务选择，无需重新生成业务规范。空字符串错误状态来源及 `error && <Text>` 已由代码核实，原导航推断尚不能解释本次调用栈。

- 现有 `/add` 负责蓝牙发现，`/add-provision` 已承载配网状态机。
- `AddDeviceFlow` 已提供 Wi-Fi 读取、配网阶段状态、失败状态、绑定轮询、昵称保存和完成状态。
- `RowanService` 已提供房间列表 `GET /api/app/user/locations` 与设备房间归属 `PUT /api/app/devices/{deviceID}/location`。
- 用户要求的设计稿包含 Wi-Fi 未连接/5GHz 弹窗、SSID 回填、阶段进度、失败重试、昵称 20 字限制和房间底部抽屉。

## 决策树与限制

1. 页面拆分：沿用既有 `/add` 与 `/add-provision`，通过独立 `AddDeviceProvision` 组件实现 UI。
2. Wi-Fi 检查：沿用系统 Wi-Fi 读取结果；未连接或 5GHz 使用系统弹窗，去连接跳转系统 Wi-Fi 设置，失败回退系统设置。
3. 配网协议：不改现有 `AddDeviceFlow` 和 API 契约，UI 映射已有阶段，不虚构百分比之外的设备回报。
4. 房间：复用既有房间读取和归属写入；房间默认选择策略和真机视觉待验收。
