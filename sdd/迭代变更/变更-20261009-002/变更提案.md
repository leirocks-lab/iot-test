# CHG-20261009-002 认证表单路由化与返回入口

状态：in_progress

## 目标

认证入口 `/auth` 只展示品牌和登录、注册操作；登录、注册、重置密码分别使用独立路由。表单页左上角提供返回入口页的真实路由返回操作。

## 范围

- RF-0002 启动与基础初始化（REQ-002）
- RF-0006 邮箱注册（REQ-009 至 REQ-014）
- RF-0007 邮箱密码登录（REQ-015）
- RF-0009 找回与重置密码（REQ-018 至 REQ-021）
- 用户指令（2026-10-09）：登录或注册页面左上角显示返回按钮，并评估使用路由而不是 query params 切换。

## 决策与限制

使用 Expo Router 静态路由 `/auth/login`、`/auth/register`、`/auth/reset`。保留无 mode 的 `/auth` 入口及旧 query 参数兼容；认证服务和 API 契约不变。GrillMe 指定插件路径当前不可用，已记录于上一变更包问询记录。
