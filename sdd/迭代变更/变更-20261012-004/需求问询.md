# 需求问询

## 范围

本次仅处理全局 Loading 组件的动画实现、Hook 封装和资源文件名规范，不扩展业务页面行为。

## 已核实事实及来源

- `src/components/Loading.tsx` 当前仅渲染静态 48×48 方块。
- `assets/images/loading/` 包含 60 个关键帧，原文件名带中文“加载动画”。
- 项目使用 Expo SDK 57、React Native 0.86，现有 Busy 组件仍被多个页面使用。
- 用户明确要求实现关键帧 loading 动画、封装 hook、去除中文文件名。

## 决策树

### 第 1 轮：Hook API

- 建议：`useLoading(initialVisible?)` 返回 `visible/loading` 状态、`show`、`hide`、`toggle` 以及绑定状态的 `Loading` 组件，便于页面按需渲染。
- 结果：依据用户明确的“提供给各个页面使用”要求采纳；不改变现有 Busy 调用方。

### 第 2 轮：动画实现

- 建议：使用 React Native `Image` 和 `setInterval` 循环切换静态资源，默认 50ms（约 20fps），组件卸载时清理定时器。
- 结果：依据已有关键帧资源和 Expo 内置能力采纳。
