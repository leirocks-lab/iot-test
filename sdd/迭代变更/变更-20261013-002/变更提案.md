# CHG-20261013-002 首页设备概览视觉与选择模式

状态：in_progress

## 问题与目标

依据用户 2026-10-13 提供的首页设计稿，调整首页顶部品牌、房间标签、产品概览卡片、长按多选态和批量删除操作，使现有首页在 Android/iOS 上可观察行为与设计稿一致。

## 范围与规范差异

| 功能 ID | 原版本 → 目标版本 | 原始条目 | 变化前 → 变化后 | 关联 AC |
| --- | --- | --- | --- | --- |
| RF-0011 | 0.2.0 → 0.3.0 | REQ-023～026 | 保留 HOME-01 加载和房间筛选，改为设计稿房间标签视觉 | RF-0011-AC-001、006、007 |
| RF-0012 | 0.2.0 → 0.3.0 | REQ-027、028、030 | 卡片增加设计稿在线指示灯、产品名称/型号和产品图区域 | RF-0012-AC-001、002、003 |
| RF-0013 | 0.2.0 → 1.1.0 | REQ-029 | 使用 poweron/poweroff 资源表达开关状态，继续由 MQTT Shadow 确认结果 | RF-0013-AC-001、002、003、007 |
| RF-0014 | 0.3.0 → 0.4.0 | REQ-031、032 | 长按进入独立选择模式；顶部完成/取消；底部删除设备；删除后仍留在选择模式 | RF-0014-AC-001～008 |

## 用户明确要求

顶部使用 `assets/images/home-logo.png`；房间使用标签切换；卡片在线为绿色圆点、离线为灰色圆点；开关使用 `poweron-icon.png` / `poweroff-icon.png`；选择框使用 `multiple-choice.png` / `multiple-choice-selected.png`；长按进入选择模式；无选中时删除不可用；删除后不自动退出，只有完成或取消退出。

## 影响与待确认

- 设计稿未提供与 HOME-01 产品字段一一对应的本地产品位图；继续优先使用接口 `product.image`，无图时使用现有 `DeviceGlyph`，不虚构新的产品资源或 API。
- 真实设备在线状态、Power 状态和解绑结果仍以现有 DEVICE-01/MQTT 与 MORE-02 适配层为准。
- GrillMe 技能入口要求调用 `grilling`，但当前环境未提供可调用的 Skill 工具；本限制记录在 `需求问询.md`，不伪造问询结果。

## 确认记录

用户在本轮消息中直接给出设计稿、资源文件和交互规则，作为本变更 UI 范围与可观察行为依据。规范保持 draft，交付状态 in_progress，业务验收待真实设备/平台验证。
