# CHG-20261013-002 实施计划

## 输入与边界

关联 RF-0011、RF-0012、RF-0013、RF-0014 及现有 HOME-01、DEVICE-01、MORE-02；不新增 API，不改变房间/设备数据契约，不扩展设备控制能力。

## 实现方案

1. 扩展通用 Page 以支持首页自定义顶部内容和固定底部操作栏。
2. Home 使用 home-logo 作为品牌区域，房间列表渲染为横向标签并保留偏好保存。
3. DeviceCard 保留 ShadowSession 控制链路，按 product.image/DeviceGlyph 显示产品，按在线状态和 Power 确认值显示指示灯、名称、型号和图标化开关。
4. 增加独立 editing 状态。长按或编辑态点击卡片切换选择；顶部完成/取消清理编辑态；删除仅在有选中项时可用，删除完成后保留编辑态并刷新数据。
5. 执行 specs、lint、typecheck 和相关测试，记录实际结果。

## 接口与兼容

不新增依赖或接口；沿用 Expo SDK 57、React Native 0.86 和现有服务适配器。无法获取 product.image 时回退现有 SVG 产品图。

## 验证与交付

验证房间标签、卡片状态、开关禁用条件、长按选择、删除后留在选择态和完成/取消退出。未执行真实 Android/iOS 设备验收前不将 AC 标为 verified。
