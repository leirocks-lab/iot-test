# CHG-20261022-001 真实 Wi-Fi 密码校验门禁修复

状态：in_progress；规范状态：draft。

## 问题与目标

安卓用户已扫描到设备，输入 Wi-Fi 密码后，本地因没有提供校验器而抛出“真实 Wi-Fi 密码规则尚未配置”。按用户 2026-10-22 的明确指令先核查来源，再移除无来源的校验门禁。

## 范围与规范差异

| 功能 ID | 原版本 → 目标版本 | 原始条目                | 变化前 → 变化后                                                             | 关联 AC                  |
| ------- | ----------------- | ----------------------- | --------------------------------------------------------------------------- | ------------------------ |
| RF-0020 | 1.4.1 → 1.5.0     | REQ-051（Excel 第52行） | 校验器缺失即拒绝 → 校验器可选，默认仅执行来源支持的非空及 UTF-8 254字节边界 | RF-0020-AC-005、019、023 |

MINOR：兼容放开此前被门禁拒绝的输入场景；保留 RF/AC 编号并新增 AC-023。未新增业务范围或云端接口。

## 影响与待确认

`RealAddContract.validatePassword` 改为可选；提供时必须为函数并继续执行。已有提供校验器的接入配置兼容，无数据迁移。Mock 规则、UI 非空按钮条件和密码清理策略不变。绑定码、设备 Token、工厂确认、等待预算仍待真实接入，不能因本次修改推断完整配网可用。

## 确认记录

确认依据为用户本轮实际指令，见[需求问询](需求问询.md)。资料未给规则则不限制的处理已获明确授权，不重复请求同一确认；其他未解决接口分支继续待确认。

# CHG-20261022-001 变更提案

## 目标

按设计稿重构房间管理交互，展示房间及设备二级列表，提供底部改名抽屉、编辑模式拖拽排序/跨房间移动/删除，以及独立新增房间页面。

## 范围

- RF-0040：设备拖拽跨房间后通过 ROOM-01 保存归属。
- RF-0047：ROOM-03 数量和 HOME-01 设备明细组成可展开列表。
- RF-0048：新增房间页面和推荐名称。
- RF-0049：底部抽屉修改房间名称。
- RF-0050：编辑模式房间排序，完成时统一保存。
- RF-0051：左滑删除空房间；含设备时提示“当前房间还有设备无法删除”。

## 规范差异与版本

兼容新增 UI 场景与交互，目标功能规范版本按 MINOR 提升：RF-0040 0.6.0、RF-0047 0.4.0、RF-0048 0.4.0、RF-0049 0.4.0、RF-0050 0.4.0、RF-0051 0.4.0。规范保持 draft，交付状态在实现验证后更新。

## 验收关联

新增 AC：列表展开设备、抽屉改名、编辑拖拽/跨房间移动、含设备删除提示、推荐名称与 20 字限制、确认创建后返回列表。

## 确认依据与待确认项

依据：用户 2026-10-22 对本变更问询三项回答及提供的五张 UI 设计图。待确认：真实后端对 ROOM-01 与 ROOM-06 的并发/原子保存能力，需在真机联调时验证。
