# CHG-20261022-001 变更提案

## 目标

按设计稿重构房间管理交互，展示房间及设备二级列表，提供底部改名抽屉、编辑模式拖拽排序/跨房间移动/删除，以及独立新增房间页面。

## 范围

- RF-0040：设备拖拽跨房间后通过 ROOM-01 保存归属。
- RF-0047：ROOM-03 数量和 HOME-01 设备明细组成可展开列表。
- RF-0048：新增房间页面和推荐名称。
- RF-0049：底部抽屉修改房间名称。
- RF-0050：编辑模式房间排序，完成时统一保存。
- RF-0051：左滑删除空房间；含设备时提示“当前房间还有设备无法删除”。

## 规范差异与版本

兼容新增 UI 场景与交互，目标功能规范版本按 MINOR 提升：RF-0040 0.6.0、RF-0047 0.4.0、RF-0048 0.4.0、RF-0049 0.4.0、RF-0050 0.4.0、RF-0051 0.4.0。规范保持 draft，交付状态在实现验证后更新。

## 验收关联

新增 AC：列表展开设备、抽屉改名、编辑拖拽/跨房间移动、含设备删除提示、推荐名称与 20 字限制、确认创建后返回列表。

## 确认依据与待确认项

依据：用户 2026-10-22 对本变更问询三项回答及提供的五张 UI 设计图。待确认：真实后端对 ROOM-01 与 ROOM-06 的并发/原子保存能力，需在真机联调时验证。
