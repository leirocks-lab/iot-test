# CHG-20261014-006 实施计划

## 输入与边界

依据[变更提案](变更提案.md)、[需求问询](需求问询.md)、RF-0046 / REQ-096、MORE-02 与 HOME-01。最终共同理解确认后先更新规范与版本记录，再改业务代码。

## 实现方案

在当前设备设置页展示含设备名称、设备 ID、账号 `userID` 的本人解绑确认。取消不请求；确认后只允许一次正在进行的 MORE-02。用独立业务流程管理提交、读回、状态与账号/设备上下文；结果未知时 HOME-01 读回，不自动再次 DELETE。收到明确成功或可确认目标已不在当前账号首页时，只关闭目标设备会话及该设备运行时缓存，返回并刷新首页。错误码 1361/1362 不映射成功。失焦或会话变化取消在途请求，迟到结果不作用于其他上下文。

## 接口与兼容

MORE-02 保留 Bearer/租户与现有真实适配；动态设备 ID 编码并透传 AbortSignal。`RowanService` 默认在 401 后刷新 token 并重发，故本操作必须显式关闭该自动重发，以满足单次 DELETE；HOME-01 仍可按读取接口惯例刷新会话。Mock 用专属 MORE-02 错误码和有状态关系模拟；真实模式失败不回退 Mock。不改服务端、物模型、持久化结构，也不调用 MORE-03 模拟级联。

## 验证与交付

用 Mock 与合成真实 HTTP 验证确认取消、成功/失败/结果未知、读回、1361/1362、目标设备清理、其他设备保留、账号/设备切换；运行格式检查、lint、typecheck、Vitest、SDD 索引/检查及 Android/iOS JS 导出。无真实账号、MQTT 设备或双平台实机时保持 draft/in_progress，不标 verified/released。
