# CHG-20261015-001 实施计划

## 技术方案

1. 在 `Home.tsx` 使用 React Native 官方 `Modal` 实现透明遮罩和气泡容器。
2. 将原首页 header 右侧添加菜单移除；保留 logo，房间标签栏包裹横向滚动标签和右侧房间列表按钮。
3. 从已加载的 `groups` 计算全屋与各房间设备数量；点击条目复用 `homeRoom` 偏好保存逻辑。
4. 点击“房间管理”关闭气泡并使用 Expo Router 跳转 `/rooms`。

## 兼容性与边界

- 不修改 HOME-01、DEVICE-01 或服务端数据契约。
- 选择模式下禁用房间按钮并关闭气泡，避免与批量选择操作冲突。
- 底部导航的添加设备/扫一扫入口保持不变。

## 验证方案

- `pnpm lint`
- `pnpm typecheck`
- `pnpm test`
- `pnpm specs:index`、`pnpm specs:check`
- 手工检查：全屋及房间数量、标签切换、遮罩关闭、房间管理跳转、选择模式互斥。
