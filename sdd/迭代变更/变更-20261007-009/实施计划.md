# CHG-20261007-009 实施计划

## 输入与边界

按用户已批准四期计划覆盖全部既有RF和AC；不新增商城、个人资料、推送或后台业务。源码在当前干净检出的codex/sdd-mock-app分支实施，不复制尚未Git跟踪的来源；未建立外部发布。

## 实现方案

1. HTTP Mock 与真实fetch实现共用HttpClient；业务服务负责序列化、会话单次刷新和取消轮次。
2. Mock数据库持久化，账号隔离，事务串行提交；统一设备、房间、日程、分享及OTA数据。
3. BLE协议字节编解码共用于Mock传输和配网状态机；设备Shadow模拟AT/55AA回报，匹配reported才确认。
4. Expo Router路由薄层，React Native页面和表单组件在src/screens；三语言、主题、温度显示及范围内入口。
5. 安全会话使用SecureStore；Mock数据库是开发数据，不存真实密码和设备私钥。

## 接口与兼容

HttpRequest增加query和AbortSignal；通信模式及API地址通过配置选取。Mock假设集中版本化；数据含schemaVersion，未知版本明确错误不覆盖。真实设备传输通过注入驱动接入，不自动模拟成功。

## 验证与交付

先写行为测试并观察失败，再实现；契约、会话、账号隔离、CRUD、配网和Shadow故障测试；运行索引、规范检查、lint、typecheck、业务测试、doctor、Android/iOS导出。真机未执行时保留待验收，规范不标verified/released。


本期范围以变更提案表为准；共享适配、存储与模拟配置引用一期，不复制事实源。
