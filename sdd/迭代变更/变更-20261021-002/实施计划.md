# CHG-20261021-002 实施计划

## 输入与边界

- 关联 RF-0020 1.4.1、REQ-054/REQ-056、RF-0020-AC-008/010、`AddDeviceFlow` 阶段回调和 `AddDeviceProvision` 进度页面。
- 不改 PAIR-04/05/06/07、设备 0822 数据、轮询间隔、密码生命周期或路由参数。

## 实现方案

1. 在 `AddState` 增加非敏感 `deviceProgress`，由已收到的 `A1/A0` 至 `F1/F0` 事件映射为 12 个事件点；未知状态保留上一值。
2. 绑定确认成功时将快照置为 1；进入绑定轮询前保持 12/13，避免把轮询中的状态显示为已完成。
3. 用 `react-native-svg` 的动画 Path 绑定弧长偏移，进度快照变化时平滑追踪；失败分支继续归零。
4. 增加状态映射单元测试，并运行业务测试、类型、lint 与 SDD 检查。

## 验证与交付

- 自动验证覆盖每个阶段的进行中/完成映射、未知事件不推进、绑定槽位和失败归零。
- Windows/Expo Web 静态验证不能替代 Android/iOS 真机视觉与真实设备阶段回报；这些限制保留在交付记录。
