# CHG-20261021-002 配网进度弧形实时推进

状态：in_progress；规范状态：draft

## 目标

修复添加设备配网页顶部半弧形进度条使用固定百分比的问题，使弧形和百分比只随 `AddDeviceFlow` 已收到的真实设备阶段事件推进，并保持失败归零和绑定未确认不显示完成。

不新增业务范围、API、协议字段、设备阶段或验收编号；版本为 PATCH，补充已确认 UI 行为和实现引用。

## 影响与待确认

- 影响 `AddState` 的非敏感进度快照、配网进度组件和相关单元测试。
- 真实 0822 阶段事件、Android/iOS 原生视觉和完整业务闭环仍需真机验收。

## 确认依据

用户于 2026-10-21 明确要求顶部半弧形进度条“跟着进度实时前进，重新实现”。既有 RF-0020-AC-008/010 和状态机实现确认真实事件来源；未增加范围外业务。
