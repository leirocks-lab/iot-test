# CHG-20261024-002 实施计划

## 输入与边界

依据[变更提案](变更提案.md)与[需求问询](需求问询.md)，更新 59 份规范，业务范围与来源保持。

## 实现方案

1. 删除模拟 HTTP、设备驱动/会话、本地云、MCU、数据库、目录/帮助、二维码和映射；提取真实依赖的公共类型、预算工具和内存存储。
2. Runtime 仅装配 RealHttpClient、原生 BLE、系统 Wi-Fi、RealtimeDeviceSession 和显式注册契约；未知配置或缺项不回落。
3. 删除模拟 UI、故障注入和快捷开关模拟连接；找回密码按既有 AUTH-01/02/07 实现，保留真实诊断。
4. 改写有效业务测试为最小端口替身，删除纯模拟器测试；检查导出包无运行时模拟业务。

## 接口与兼容

CommunicationConfig 移除 httpMode/deviceMode，遗留 mock 参数显式拒绝。真实会话仍按 API/租户隔离；旧模拟数据不迁移、不读写。保留已有显式真实 MQTT 配置；未提供配网、二维码、控制/维护/告警契约时禁止相应操作。无需后端迁移或新增依赖。

## 验证与交付

先建立真实模式配置与缺项边界回归，观察失败再实现。执行 lint、typecheck、全部测试、verify:config、Android/iOS export、specs:index/check；维护工具若修改再执行 specs:test。测试覆盖真实 HTTP 错误、会话隔离、找回密码、缺项、取消释放及无演示结果。实际命令与平台证据写入任务清单，未联调平台不报告通过。
