# CHG-20261015-002 实施计划

1. 先更新 RF-0017 规范与版本记录，保留稳定 RF/REQ/AC 编号并关联本 CHG。
2. 使用 Expo SDK 57 的 `expo-camera` `CameraView` 和 `useCameraPermissions`；页面聚焦时自动申请权限，离页/后台停止扫码。
3. 使用绝对定位覆盖层还原设计稿：顶部导航、扫描框四角、橙色扫描线、说明文字和相册按钮；用 Animated 循环实现扫描线。
4. 对权限拒绝和二维码错误显示短时 toast；拒绝权限 toast 后返回上一页，二维码错误保持相机可用。
5. 合法 share 码确认后读取当前账号设备列表并展示结果卡片；列表暂不可用时提供重试；product 码继续遵循 RF-0017 进入添加流程。
6. 执行 `pnpm specs:index`、`pnpm specs:check`、`pnpm lint`、`pnpm typecheck`、相关 Vitest 测试；记录真机验收限制及既有来源哈希阻塞。
