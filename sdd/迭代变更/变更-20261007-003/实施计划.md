## 实施中确认的配置加载适配

Expo 配置加载器只转译配置入口，应用内 TypeScript 品牌模块需先注册 tsx/cjs。依据官方配置文档增加纯开发依赖 tsx；expo install 被当前配置加载失败阻塞，因此使用 pnpm add --save-dev tsx 安装。该适配不改变业务规则或验收预期。

配置兼容说明：pnpm 11 将项目级非注册表设置及 allowBuilds 保存在 pnpm-workspace.yaml。保留该设置文件但去除 packages、catalog 等工作区定义；锁文件仅有根应用 importer。此文件名不代表仍采用 Monorepo。

## SDK 兼容性补丁更新

初次 Doctor 20/21 项通过，指出 @expo/ui 57.0.21、expo 57.0.26、expo-constants 57.0.20、expo-linking 57.0.11、expo-router 57.0.24 低于 SDK 57 当前要求的补丁版本。使用 expo install --fix 更新为 SDK 57 推荐补丁，不升级 SDK 主版本；更新后重跑工程检查、配置、CNG 和导出。
