# CHG-20261014-005 实施计划

## 输入与边界

依据 [变更提案](变更提案.md)、[需求问询](需求问询.md) 和 RF-0041 0.4.0，覆盖 REQ-086/089、MORE-01/03、AC-001～013。先更新规范，后修改业务代码。当前设备更多页沿用既有基础组件；分享中心 UI 不进入本轮。

## 实现方案

真实读取适配验证列表、`userID`、`bindingRole`，接受用户摘要缺省/null；Mock 保持有状态且用专属错误码和角色边界模拟。页面对返回项按角色标识并只数 `mbr`；以昵称和 `userID` 标识且不显示原始手机/邮箱。仅设备详情确认当前用户是 `sa`、列表目标为 `mbr` 时出现移除入口；确认内容包含当前设备与目标身份。取消不发送 DELETE。

移除操作加目标级锁、等待预算与 AbortSignal；成功读回成员列表。明确权限/关系错误不假删，刷新角色和列表。结果未知时只读 MORE-01 核对，不自动重发；目标仍在或读取失败则保持待核对，直到可核实当前关系。失焦、设备或会话变更取消请求并隔离迟到结果，同一上下文重新进入时先核对待处理结果。

## 接口与兼容

不变更服务端、MQTT、物模型或本地持久化结构；REST 路径编码动态标识，继续用既有 Bearer/租户配置。真实模式失败明确报错，不回退 Mock。部署快照仅作本轮 HTTP 适配依据，不证明真实联调成功。观察员若由服务端返回可按角色展示但绝不构造；真实环境目前不可完成观察员可见 AC。

## 验证与交付

Mock 和合成真实 HTTP 验证正常/空/缺摘要/异常响应、管理员/成员/观察员权限、取消确认、重复提交、移除结果未知与读回、1371/1372/1373、迟到请求与账号/设备切换。运行 lint、typecheck、Vitest、SDD 索引检查和 Android/iOS JS 导出；记录环境、输入、预期、实际和限制。无真机与真实后端时保持 draft/in_progress，不标 verified/released。
