# CHG-20261013-001 实施计划

## 技术方案

- 在自定义底部导航组件中使用 `react-native-safe-area-context` 的 `useSafeAreaInsets` 获取系统底部安全区。
- 将底栏容器高度设置为基础导航高度加 `insets.bottom`，将 Home/Mine 点击区域固定在基础导航区域内，并同步抬高中央 Add 按钮。
- 使用底部填充视图覆盖 iOS Home Indicator 和 Android 导航栏区域，保持原有导航外观与交互。

## 验证

- `pnpm lint`
- `pnpm typecheck`
- `pnpm specs:index` / `pnpm specs:check`（当前受既有 `SRC-BLE-0822-001` 来源哈希不匹配阻塞）
