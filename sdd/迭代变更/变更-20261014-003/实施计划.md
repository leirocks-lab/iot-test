# CHG-20261014-003 实施计划

## 输入与边界

仅 RF-0018 0.4.0、REQ-042～045，关联 [提案](变更提案.md)、[问询](需求问询.md) 及 [目标规范](../../业务功能/添加设备/产品目录/产品品类、手动与推荐产品选择/功能规范.md)。UI 使用现有组件，正式视觉还原和真实联调后置。

## 实现方案

1. 建立目录类型和响应解析模块；PAIR-03 必须在泛化详情路径匹配之前处理。保留多语言名称、详情多图/参数/介绍、真实能力值；不按型号构造能力。
2. RowanService 增加品类方法、目录分组类型，保持 type=text 和 Accept-Language/Bearer。可选 brandId 仅显式配置才发送。
3. 独立 ProductCatalogFlow 管理目录/详情请求、筛选、重试与取消；各请求携带 AbortSignal、轮次和账号会话检查。目录失败不阻断独立蓝牙入口；详情失败清空旧目标，不沿用旧能力。已有全部有效 sort 时稳定升序，缺 sort 保留返回顺序，不冻结后端同值顺序。
4. Add 接入目录组件，显示品类、推荐/手动列表、产品图片与详情；详情选择后复用现有蓝牙扫描/配网能力检查，发送配网前仍由既有流程重读详情。资料未知或未接入路线明确不可继续，不新增配网 SDK。
5. buyLink 只在公开静态信任配置明确允许的 HTTPS origin 下显示可执行入口；无正式配置保持空列表，不猜生产域名。链接失败显示错误。Mock 独立提供三语言品类、详情参数等演示数据，不改变真实契约。

## 接口与兼容

没有新接口、数据迁移、依赖安装或原生配置变化。Product.image 保留首图兼容旧调用者，新增 images/parameters/introduction 可选字段；configType 的已见字符串/数组兼容，不生成缺失能力。真实模式未提供契约/配置时明确不可用，不回退 Mock。

Expo package 为 ~57.0.27，已查阅 [SDK57](https://docs.expo.dev/versions/v57.0.0/)、[文档索引](https://docs.expo.dev/llms.txt)、[Router/useFocusEffect](https://docs.expo.dev/versions/v57.0.0/sdk/router/)、[Image](https://docs.expo.dev/versions/v57.0.0/sdk/image/) 和 [React Native Linking](https://reactnative.dev/docs/linking)，按页面失焦取消请求、图片错误占位及链接 Promise 错误处理。
