## 事实与适配

| 内容 | 核实事实 | 实现处理 |
| --- | --- | --- |
| 品类 | PAIR-03 data 数组，name/string、value/string；名称已由服务端按 Accept-Language 精确→en→首键选择 | 显示返回 name，value 筛选；优先匹配 category 路径，避免被当详情 |
| 产品分组 | PAIR-01 返回 category、categoryName 多语言对象、products 数组 | 保留分组及译名；品类入口仍来自 PAIR-03 |
| 产品字段 | name 可能缺失，id 为稳定标识；能力字段来自产品数据 | 名称缺失可显示实际 id，不制造产品名称或配网能力 |
| 图片 | Word 表写 String，响应示例/部署快照是 string[] | 保留已见 scalar/array 内容；image 首图兼容旧调用者、images 展示多图 |
| 配网方式 | Word 表写 String，部署说明明确 configType 数组，示例 A/B/C | 保留数组；兼容已有 Mock 字符串；只复用现有 B+wifi+bluetooth 路线，其他能力显示但不猜实现 |
| 参数 | Word 表写 Object，示例/部署快照为对象数组；items 为字符串属性，没有严格要求每项必须 key/value | 保留已见对象/数组；key/value 成对展示，其他属性按实际键值显示 |
| 介绍 | PAIR-02 必传 type；无指定形态内容为 null | type=text，保留 null，不回退 URL 形态 |
| 不存在 | 产品不存在/未发布为业务码 1091 | 保留真实错误；Mock 目录对不存在也使用 1091；详情失败清空旧可执行目标 |
| brandId | PAIR-01/03 可选，仅品牌目录差异才配置；示例 as/zafro 不证明 rowan 可用 | 移除默认猜测 rowan，仅静态明确配置时发送 |
| sort | 数值存在，但方向和同值顺序未定义 | 用户本轮 Q2 明确选择前端完整值升序、同值稳定、缺值保留响应顺序；后端约定仍待确认 |
| buyLink | 存在链接字段，无实际信任名单 | 公开静态 origin 配置默认空；仅显式可信 HTTPS 来源可执行，示例域名不成为生产信任 |
