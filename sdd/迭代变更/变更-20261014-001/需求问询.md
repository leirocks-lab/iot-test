# CHG-20261014-001 需求问询

## 已核实事实

- 用户要求删除首页刷新按钮并改为下拉刷新。
- 首页已有 `load()`，包含 HOME-01、AbortController、超时和账号隔离；仅需替换入口。
- Expo SDK 为 57，React Native 为 0.86.3。
- React Native 官方 `RefreshControl` 支持 ScrollView 下拉刷新，受控属性为 `refreshing`，回调为 `onRefresh`。

## 决策

1. 使用官方 RefreshControl，不增加第三方依赖：与当前 SDK 兼容且维护成本最低。
2. 公共 Page 增加可选 refreshControl 注入；仅 Home 传入。
3. editing 选择模式禁用刷新；普通状态允许下拉并复用现有 load。

GrillMe 技能入口在当前会话不可调用；本次为明确 UI 实现和官方组件选择，记录事实与限制，不伪造问询结果。
