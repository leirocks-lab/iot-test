# CHG-20261014-001 首页下拉刷新

状态：in_progress

## 目标

删除首页底部 Refresh 按钮，使用 React Native 官方 `RefreshControl` 实现下拉刷新。

## 范围

仅涉及首页刷新入口和公共 Page 的 ScrollView 扩展。沿用现有 HOME-01 请求、超时、取消、账号隔离和 App 回前台刷新逻辑，不新增依赖或接口。

## 方案依据

项目使用 Expo SDK 57 / React Native 0.86.3。React Native 官方 RefreshControl 直接集成 ScrollView，`refreshing` 受控、`onRefresh` 触发刷新，Android 支持 colors，iOS 支持 tintColor。无需引入第三方库。

## 业务影响

RF-0011 首页加载与房间导航：刷新入口由按钮改为下拉手势，现有房间筛选和刷新请求语义保持不变。选择模式期间禁用下拉刷新，避免误触和编辑状态冲突。

## 限制

未执行真实 Android/iOS 设备上的手势验收；规范保持 draft，交付状态 in_progress。
