# CHG-20261027-002 实施计划

1. 实现前更新 RF-0012/0022 规范和版本记录。
2. Runtime 缓存同登录上下文/设备的托管会话；不再以底层 stop 删除逻辑会话。退出/换号/解绑/销毁终止并清理。
3. 托管会话对已就绪 connect 幂等、连接中单飞，页面 AbortSignal 只影响该调用者。共享确认属性、控制等待、事件和错误。失败分类不依赖错误文案。
4. AppProvider 唯一前后台监听通知 Runtime；页面和配网取消局部请求/监听，不 close。后台不主动关闭且不启动重试；前台按批准退避恢复，每次重新签发凭证和全量同步，不重放控制。
5. 连接日志关联逻辑会话 ID、attempt 与结构化关闭原因；复用不产生新连接日志。
6. 测试先行：缓存身份、单飞、调用者取消隔离、后台/前台及退避、永久错误、资源清理、旧回调隔离和控制不重放。运行全量、lint、typecheck、specs:index/check，输出报告。

Ruling：使用独立托管层包装既有 ControlledDeviceSession，保留低层一次连接语义，以降低协议改动风险。Web 现场验证优先使用已有运行环境；缺少可运行或可访问环境时明确记录，不能用 Node 替身冒充真机跨页验证。所有测试数据限测试用途，不注册运行时 mock。
