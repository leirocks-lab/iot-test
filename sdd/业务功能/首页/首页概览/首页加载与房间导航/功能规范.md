# RF-0011 首页加载与房间导航

> 2026-10-13：关联 CHG-20261013-002，按用户首页设计稿细化品牌、房间标签、产品卡片和选择模式视觉；保持现有 API 与状态语义。

## 目标与边界

为已登录用户提供真实设备总览、房间筛选及可恢复的加载体验。仅覆盖 REQ-023～026；添加设备入口引用已有添加流程，房间增删、排序与布局偏好不在本功能内。

## 前置条件与业务规则

所有功能遵循 [公共规则](<../../../../公共规则/业务规则.md>) 和 [API 约定](<../../../../公共规则/接口约定.md>)。已确认决定详见 [CHG-20261007-004 需求问询](<../../../../迭代变更/变更-20261007-004/需求问询.md>)；本次不实现 App 代码，不将文档检查作为业务验收。

- 首次进入默认选中“全屋”；再次进入恢复当前账号上次所选页签，房间消失时回退“全屋”。全屋聚合当前账号可见设备；分组结构、未分房归属及排序须解决 C-017，不猜测响应字段。
- HOME-01 获取静态设备与房间数据。无缓存的首次请求展示骨架/加载态；有最近确认缓存时保留列表并显示刷新状态。只有成功取得空设备列表才能展示无设备状态和添加入口。
- 网络或请求失败：有缓存保留内容并提示错误和重试；无缓存显示错误与重试，不能误显示“无设备”。用户触发重试仍请求 HOME-01，不新增接口。
- 最近确认数据和页签按账号隔离并保存；退出登录时清理。登录态与权限的真实规则引用 RF-0003，不以缓存替代鉴权或保存 MQTT 临时凭证。
- 进入 Home、App 回到前台、网络恢复，以及既有登录/绑定成功回流时刷新 HOME-01；重叠触发合并请求。切换房间只改变本地筛选，不额外请求列表。
- 网络恢复后按有效设备列表恢复 MQTT 订阅；旧请求或旧账号回报不能覆盖当前账号数据。网络不可用时保留已确认数据，但不能把缓存在线标识当作当前可控制依据。

## 主流程与异常流程

### 主流程

1. 确认会话和账号，读取该账号最近确认缓存与页签记录；默认显示全屋或仍存在的已记忆房间。
2. 按有无缓存显示加载状态，调用 HOME-01；合并同一账号重叠刷新触发。
3. 成功后更新缓存和房间列表，校正已失效页签；空设备展示添加按钮，非空列表交由 RF-0012 展示卡片。
4. 恢复网络时刷新列表并恢复 MQTT；切换房间仅筛选已有数据。

### 异常流程

- 请求失败或断网：保留缓存并显示错误/重试；无缓存显示完整错误态。刷新失败不清空列表或写入空缓存。
- 刷新期间账号改变：丢弃旧账号响应及订阅，清理退出账号的缓存；不能显示其他账号设备。
- 已选房间被删除：成功更新房间数据后回退全屋，不保留无效页签。接口分组无法解析时展示可恢复错误，不伪造房间。

## 验收标准

- **RF-0011-AC-001**：给定成功返回至少两个房间和设备，进入首页显示房间页签和设备；切换房间只展示对应设备且不新增 HOME-01 请求；成功返回空设备时显示添加入口。
- **RF-0011-AC-002**：给定已有最近确认列表，断网后列表仍在且有网络提示；恢复后刷新 HOME-01 并恢复有效设备订阅，失败不显示假成功。
- **RF-0011-AC-003**：给定无缓存且 HOME-01 尚未返回，显示加载态；成功后结束加载并展示真实结果。
- **RF-0011-AC-004**：给定 HOME-01 成功返回无设备，显示无设备状态和添加按钮；点击进入既有添加流程，不生成虚拟设备。
- **RF-0011-AC-005**：给定断网，有缓存显示最近确认数据和网络提示，无缓存显示错误及重试；不将断网解释成无设备。
- **RF-0011-AC-006**：给定当前房间已选中，切换页签只改变筛选；返回该账号 Home 恢复所选房间，房间消失时回到全屋。
- **RF-0011-AC-007**：给定账号首次进入且无页签记忆，默认选中全屋；账号 A 与 B 的数据和选择不混用。
- **RF-0011-AC-008**：给定刷新失败且有缓存，保留列表、显示失败及重试入口；无缓存时显示错误态，重试重新调用 HOME-01。
- **RF-0011-AC-009**：给定进入 Home、回前台与网络恢复同时触发，合并重叠列表请求；仅切换房间不触发列表请求。
- **RF-0011-AC-010**：给定退出账号 A 后进入账号 B，A 的缓存和页签已清理；A 的延迟响应不能显示在 B 的首页。

既有 AC 编号保持原意并细化可观察场景，新场景顺序追加；验收执行结果在变更包记录，本轮不将以上业务验收标为通过。


## 房间列表气泡入口（CHG-20261015-001）

首页房间标签行最右侧提供房间列表按钮。点击后使用透明遮罩气泡展示“全屋”和所有已有房间名称及设备数量；点击条目切换当前房间、保存 `homeRoom` 偏好并关闭气泡。点击遮罩关闭气泡，点击“房间管理”跳转 `/rooms`。选择模式下按钮不可用且气泡关闭。底部导航的添加设备/扫一扫菜单保持原职责。

- **RF-0011-AC-013**：给定首页已加载房间和设备，点击标签行最右侧按钮，显示全屋及各房间名称和对应设备数量。
- **RF-0011-AC-014**：点击气泡中的房间条目后关闭气泡，首页标签和设备列表切换到该房间，并保存 `homeRoom` 偏好。
- **RF-0011-AC-015**：点击气泡外遮罩关闭气泡；点击“房间管理”进入 `/rooms`；选择模式下不打开气泡。
