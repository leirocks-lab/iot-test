# RF-0012 设备卡片与设备页入口

> 0.2.0：依据两轮 GrillMe 问询及用户最终确认重新生成。业务决定已记录，接口与依赖未完全冻结；保持 draft / unplanned，不表示已实现或已通过业务验收。

## 目标与边界

在首页展示用户可见设备的静态信息与可信实时状态，并提供到既有设备页的入口。仅覆盖 REQ-027、028、030；设备页内部控制、物模型及完整交互仍由 RF-0022 等原规范负责，本次不重新生成设备页。

## 前置条件与业务规则

所有功能遵循 [公共规则](<../../../../公共规则/业务规则.md>) 和 [API 约定](<../../../../公共规则/接口约定.md>)。已确认决定详见 [CHG-20261007-004 需求问询](<../../../../迭代变更/变更-20261007-004/需求问询.md>)；本次不实现 App 代码，不将文档检查作为业务验收。

- 卡片显示昵称、产品图、房间和基础状态；静态信息来自 HOME-01，实时状态主要来自 MQTT property/update，REST 静态成功不代表当前在线或执行成功。
- 在线、离线与运行状态必须能区分。尚未取得实时值时显示未知，或明确标注最近确认值；断网期间不能将旧状态伪装成当前实时状态。
- 设备离线时首页快速开关禁用；即使卡片仍有缓存，也不能误显示控制成功。在线判定和陈旧阈值见 C-018。
- 点击卡片携带真实 deviceID 进入既有设备页，由该页通过 DEVICE-02 加载静态信息、DEVICE-01 获取 MQTT 临时凭证；首页不重复定义设备页会话。
- 离线卡片仍可进入既有设备页查看信息；设备页控制限制引用原规范，不因允许进入而开放离线控制。

## 主流程与异常流程

### 主流程

1. 接收 RF-0011 的真实列表，按当前房间筛选显示设备卡片。
2. 建立有效订阅后用真实上报更新对应设备状态；无上报时展示未知/最近确认值。
3. 点击卡片按 deviceID 跳转既有设备页并交由该页初始化；点击卡片快速开关仅进入 RF-0013，不触发卡片跳转。

### 异常流程

- 设备离线：保留可识别静态信息，禁用首页开关但保留查看入口，不用错误缓存制造在线。
- 进入设备页后 API 返回无权限或设备不存在：按既有设备页规范展示实际错误，刷新首页关系，不误报成单纯离线。
- MQTT 断连或凭证不可用：提示状态不可确认；按既有重连约定处理，不持续轮询 REST 来替代实时上报。

### 原始 API / 通信关联

- REQ-027：HOME-01 获取用户绑定的设备列表（GET /api/app/devices）；
DEVICE-01 获取设备 MQTT 连接（GET /api/app/devices/{deviceID}/mqtt）；
property/update 回报
- REQ-028：DEVICE-01 获取设备 MQTT 连接（GET /api/app/devices/{deviceID}/mqtt）；
property/update 回报
- REQ-030：DEVICE-02 获取设备详情（GET /api/app/devices/{deviceID}）；
DEVICE-01 获取设备 MQTT 连接（GET /api/app/devices/{deviceID}/mqtt）

API 字段大小写按契约保留；物模型属性、服务和事件按产品能力确认。这里只引用范围内所需能力，不新增 REST 设备控制或后台管理接口。

### 本轮确认的数据与调用责任

HOME-01 提供元数据，DEVICE-01 提供 MQTT 连接信息，DEVICE-02 服务于既有设备页初始化。以 deviceID 关联卡片、请求和回报；具体属性、在线事件、消息新旧判定和凭证寿命未冻结，见 C-018。

## 验收标准

- **RF-0012-AC-001**：给定真实列表与对应 MQTT 上报，卡片显示昵称、图、房间及确认状态；点击以正确 deviceID 进入既有设备页并加载 DEVICE-02/DEVICE-01。
- **RF-0012-AC-002**：给定无权限、设备不存在或离线三种情形，分别展示对应结果；不把它们都解释成离线，也不轮询元数据充当实时状态。
- **RF-0012-AC-003**：给定 HOME-01 静态字段和 property/update 实时值，分别更新静态信息与状态，不以静态成功认定设备在线。
- **RF-0012-AC-004**：给定设备离线上报，显示离线并禁用首页开关；尚无实时值时显示未知或标明最近确认值，不显示控制成功。
- **RF-0012-AC-005**：给定用户点击卡片而非开关，进入对应 deviceID 的设备页，按既有规范初始化；一次开关操作不同时触发页面跳转。
- **RF-0012-AC-006**：给定离线设备卡片，点击仍可打开既有设备页查看信息，首页开关保持禁用；设备页控制规则不由本规范扩展。
- **RF-0012-AC-007**：给定旧缓存包含在线状态但当前网络不可用，不能呈现为可确认在线或允许首页控制。

既有 AC 编号保持原意并细化可观察场景，新场景顺序追加；验收执行结果在变更包记录，本轮不将以上业务验收标为通过。
