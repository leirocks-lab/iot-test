> 0.2.0：依据两轮 GrillMe 问询及用户最终确认重新生成。业务决定已记录，接口与依赖未完全冻结；保持 draft / unplanned，不表示已实现或已通过业务验收。

## 前置条件与业务规则

所有功能遵循 [公共规则](<../../../../公共规则/业务规则.md>) 和 [API 约定](<../../../../公共规则/接口约定.md>)。已确认决定详见 [CHG-20261007-004 需求问询](<../../../../迭代变更/变更-20261007-004/需求问询.md>)；本次不实现 App 代码，不将文档检查作为业务验收。

- 底部导航固定为 Home / Store / Mine；Add 不作为底部页签，放 Home 右上角；Home 无设备状态另保留添加按钮，两处都进入既有添加流程。
- Store 只展示“暂未开放”占位内容，保留 Home/Mine 导航；不请求商城 API，不展示商品、订单、支付或虚拟数据。
- Home 显示设备和房间主界面；从其他页签回到 Home 按 RF-0011 恢复该账号房间选择并刷新，编辑期间按 RF-0014 先结束编辑。
- Mine 只提供已有退出与用户偏好入口；调用与权限、加载、退出安全策略由既有规范负责，不因导航完成而批准完整 Mine 页面。
- 原首页图底栏为 Home / Add / Mine。本轮 Q5/Q6 已确认以 Excel Store 占位边界调整为 Home / Store / Mine + 独立 Add；原图仅作视觉参考，差异见 C-020。

## 主流程与异常流程

### 主流程

1. 进入首页显示 Home 选中、房间设备列表及右上角 Add。
2. 点击 Add 或无设备页添加按钮，进入既有添加流程；绑定成功回流 Home 由既有刷新逻辑更新。
3. 点击 Store 切到暂未开放占位；点击 Mine 进入只包含退出和偏好入口的范围内页面；回到 Home 恢复筛选并刷新。

### 异常流程

- Store 不提供完整业务：只呈现占位，不以未实现 API 的错误页代替占位，也不隐藏 Home/Mine 返回入口。
- 用户偏好或退出失败：交由对应功能显示结果，不能将导航切换当作保存或退出成功；离线退出规则仍依赖 RF-0010。
- 编辑或解绑中尝试切换导航：遵守 RF-0014，先结束编辑，不丢失当前处理结果。

### 原始 API / 通信关联

- REQ-033：HOME-01 获取用户绑定的设备列表（GET /api/app/devices）
- REQ-034：暂无（当前为导航占位）
- REQ-035：USER-01 获取用户设置（GET /api/app/user/setting）；
USER-02 修改用户设置（PATCH /api/app/user/setting）；
AUTH-06 登出（DELETE /api/app/session）

API 字段大小写按契约保留；物模型属性、服务和事件按产品能力确认。这里只引用范围内所需能力，不新增 REST 设备控制或后台管理接口。

### 本轮确认的数据与调用责任

Home 关联 HOME-01；Mine/设置入口引用 USER-01/USER-02 和 AUTH-06。Store 无接口；Add 调用由已有添加规范承担。仅记录导航责任，不重复实现其他功能接口。

## 验收标准

- **RF-0015-AC-001**：给定已登录用户，底部显示 Home/Store/Mine；Home 进入房间设备主界面，Mine 只有范围内退出/偏好入口，Store 只展示占位。
- **RF-0015-AC-002**：给定点击 Store 或查看 Mine，不产生商城、订单、个人资料、反馈、帮助等范围外能力，不将完整未冻结页面标为交付。
- **RF-0015-AC-003**：给定点击 Home，进入既有设备房间主界面；从其他页签返回时恢复已记忆房间并按 RF-0011 刷新。
- **RF-0015-AC-004**：给定点击 Store，显示“暂未开放”，仍可切 Home/Mine，不调用商城接口。
- **RF-0015-AC-005**：给定 Mine，仅可进入现有退出与用户偏好功能；保存、加载和退出结果按关联规范处理，不以导航成功代替业务成功。
- **RF-0015-AC-006**：给定非空首页，右上角 Add 可进入既有添加流程；给定真实无设备，同时显示添加按钮并指向同一流程。
- **RF-0015-AC-007**：给定首页布局，底栏 Add 不再作为页签；原 UI 与已确认布局的差异有 C-020 和问询记录可追溯。

既有 AC 编号保持原意并细化可观察场景，新场景顺序追加；验收执行结果在变更包记录，本轮不将以上业务验收标为通过。
