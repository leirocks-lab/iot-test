## 前置条件与业务规则

以下规则直接来自 Excel；Word 的补充仅用于明确范围内行为，冲突见末节。

- **REQ-042 / 产品品类**：调用 PAIR-03 获取品类；显示名称使用服务端多语言配置，稳定 value 用于筛选。
- **REQ-043 / 手动产品列表**：调用 PAIR-01 获取可配网产品；配网方式、连接类型和云平台由服务端配置，App 不按型号写死。
- **REQ-044 / 推荐产品**：PAIR-01 返回 recommended、sort、buyLink 和 connectType；推荐标识、排序及购买入口均由云端配置。
- **REQ-045 / 产品详情**：调用 PAIR-02 展示产品名称、型号、图片、参数、介绍及支持的配网方式。

所有功能遵循 [公共规则](<../../../../公共规则/业务规则.md>) 和 [API 约定](<../../../../公共规则/接口约定.md>)。

### 本轮问询采纳的业务决定

依据 [CHG-20261007-005 添加设备 问询记录](<../../../../迭代变更/变更-20261007-005/业务问询/添加设备.md>)。以下是业务规范目标，接口缺失时不得按猜测参数实施。

- 手动列表与推荐共享真实产品信息；无能力或不支持当前阶段配网的产品不可凭猜测继续。
- 选定产品后再次获取对应详情，产品被删除或能力变更时返回选择，不沿用陈旧配网路线。

### 问询具体决定

- RF-0018-Q-001：分类采用 PAIR-03 稳定 value；PAIR-01 的 recommended/sort/connectType 驱动目录，PAIR-02 最新详情决定可用配网方式；不按广播名或UI样图硬编码型号。
- RF-0018-Q-002：buyLink 仅作为已有配置的受信任外链入口，无链接时不显示购买操作，不开发商城；空目录显示空态，切换品类后忽略旧请求响应。

## 主流程与异常流程

### 本轮开发边界（CHG-20261014-003）

- PAIR-03 提供品类 value 与名称；不能从样例设备或产品型号推导品类。显示已返回的当前语言名称，缺翻译时使用已返回文本/稳定标识，不编造翻译。
- PAIR-01 的 recommended 决定推荐列表；手动按稳定品类 value 筛选。用户本轮 Q2 确认当前筛选列表完整有效 sort 升序、同值保持响应相对顺序；缺值保留响应顺序，不制造排序值。后端正式同值排序契约仍待确认。
- 目录与详情有独立加载、错误、空态及重试；切换品类、选另一产品、离页/后台和账号会话变化时取消在途读取，旧结果不得覆盖当前选择。
- PAIR-02 展示已返回名称、型号、图片、参数、文本介绍及能力标识。读取失败/身份不一致时不保留旧产品为当前可执行目标；未知或未接入的能力不能进入猜测配网路线。
- 目录失败不阻断既有独立蓝牙入口；本次只复用既有已接入配网路线，不新增配网 SDK/协议。实际选择发现设备时仍由既有流程重读详情。
- buyLink 仅在显式配置的受信任 HTTPS 来源匹配时展示可执行购买入口；未配置或无效不开放购买，无商城业务。真实域名名单尚未提供，本轮不以示例 URL 建立生产信任。
- 原始表/响应示例存在 image、parameters、configType 类型差异，兼容已见形状并保留内容；未知类型明确拒绝。此兼容不是资料冲突已解决。

确认依据：[需求问询](../../../../迭代变更/变更-20261014-003/需求问询.md)、[变更提案](../../../../迭代变更/变更-20261014-003/变更提案.md)。用户只确认本轮边界，不记录为新的逐题或批量授权。

### 主流程

1. 获取品类和当前产品列表，展示服务端名称与顺序。
2. 选择品类或推荐产品，加载 PAIR-02 详情。
3. 展示支持配网方式后进入相应既有流程；buyLink 仅打开已配置受信任链接。

### 异常流程

- 目录失败可重试，空态不填示例设备；详情404阻止进入配网。
- 缺少/无效链接不显示可执行购买动作，品类快速切换不被旧响应覆盖。
