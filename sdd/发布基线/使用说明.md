# App 发布基线

尚无真实 App 发布基线。发布时创建 `应用-<实际版本>/发布清单.yaml` 和 `发布说明.md`，使用 [发布模板](<../规范模板/发布清单模板.yaml>)。

发布清单记录完整规范 Git SHA、功能 ID/版本/仓库中功能规范目录下的相对路径、关联 CHG。该提交中的规范必须 approved 且 verified 或 released；功能集合只含本次真实交付内容。模板里的占位值不能直接用于真实发布。

先提交规范和验收记录取得 SHA，再创建引用它的清单。不要将 manifest 自身所在提交要求为自己的 spec_git_commit。历史恢复用 git show <SHA>:sdd/<功能路径>；来源原文件和登记需随规范提交，不能依赖开发者机器上的未跟踪文件。

运行 pnpm specs:check 验证指定提交中实际存在的规范版本与交付状态。发布说明应列业务变化、已知限制和关联变更，不把来源文档 V1.4 当作 App 发布版本。
