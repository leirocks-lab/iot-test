# 手机悬浮日志控制台

2026-10-25 用户在确认方案及隐藏方式后回复“确定”，授权实现。此项属于工程调试工具，不修改产品业务规范、接口、RF 版本或 CHG。当前工作区无未提交修改，在原目录实施，保留可审查的未提交改动。

开发模式（`__DEV__`）启动日志采集与悬浮入口，发布构建不加载该模块。采集 console 的 log/debug/info/warn/error，覆盖现有 HTTP、MQTT、蓝牙及业务输出，保留电脑输出原有参数和行为。原生日志、启动 JS 前的崩溃不在此面板采集范围。

入口为可拖动 LOG 按钮，限制在屏幕安全区域内，点击打开深色日志面板。面板显示时间、级别、正文；提供级别筛选、关键词搜索、清空、复制当前筛选结果、收起及隐藏入口。Android 返回键收起面板。完全隐藏后通过开发菜单“显示日志控制台”恢复；应用重新启动也恢复入口。隐藏仅改变 UI，不停止本次开发会话日志采集。

内存仅保留最近 500 条，每条最多 8192 字符，列表虚拟化，采集通知最多每 200ms 一次；不持久化，不上传。沿用 diagnosticSnapshot 的结构化脱敏和边界限制，解析可识别的 JSON 字符串后脱敏，不触发 getter，不因循环对象或异常 sink 影响业务。自由文本的自定义秘密不能保证识别，分享前仍需检查。

通过 Expo SDK 57 对应文档核对 DevSettings、PanResponder、Modal 和 Clipboard 接口。复制使用 SDK 匹配的 expo-clipboard；需重新构建开发客户端使新增原生模块生效。剪贴板失败显示提示，不能导致 App 崩溃。

验证：日志容量与截断、循环及脱敏、批量通知与坏订阅隔离、过滤与导出、console 原输出、重复安装、防递归、隐藏恢复；运行 lint、typecheck、相关及全量测试，并按实际环境报告 UI/真机验证范围。
