## 修复内容

1. 会话增加可选 `online` 状态，由协议已有的在线映射产生，并通过 ControlledDeviceSession 传至页面。尚未同步、断连、映射缺失、字段缺失或值未识别时保持未知，不根据 `Online` 等字段名称猜测协议。
2. 卡片在线圆点和状态文字使用会话状态；REST 缓存不再用来确认当前在线或直接阻断已确认的在线会话。
3. 无确认电源值时显示问号和“开关状态未知”可访问标签，禁用控制，不再默认为关机。
4. 保留连接中的会话引用，显示连接失败、通信断开和控制能力缺失的实际错误。旧连接的异步失败不能覆盖当前连接。
5. 发送中显示 ActivityIndicator，并提供 busy 语义；继续禁用重复操作，不提前翻转确认电源值。

主要文件：`src/screens/Home.tsx`、`src/protocol/device-session.ts`、`src/protocol/controlled-session.ts`、`src/protocol/classic-shadow.ts`。

## 方法和限制

组件诊断执行实际 DeviceCard 函数，使用受控 Hook、原生组件、导航和会话替身；没有实际 React Native 渲染器或 AWS Broker。UI-01/04 现在明确注入“协议已确认的会话 online 状态”，不通过原始字段名称推断。新增会话/协议测试负责验证这种状态如何从正式适配器契约传递出来。

当前 `rowan-v16-shadow` 仍未注册产品在线/控制字典和控制能力映射。**因此实际运行可能显示“状态未知”和能力未配置提示，快速开关保持禁用；本次不会将模拟器中的 Power/Online 字段直接硬编码为产品契约。** 这表示页面如实反馈缺失信息，不表示已经完成真实产品接入。

本次没有改变自动重连、STS 定时换证策略，没有进行 Android/iOS 真机或真实设备开关验收。前后台资源管理、离线设备路由和独立开关处理函数的原有检查继续通过。
