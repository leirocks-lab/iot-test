## 评审与限制

首次契约编译因原生未实现新方法而失败，保留为开发 RED，不作为业务失败或测试通过。独立只读评审指出后台延迟观察的可见性与 Native→JS 队列积压两个 P2；加入真实页面生命周期门禁、每观察一个在途事件加一个最新待发 DTO、精确 ACK 和最多8个桥接观察句柄后，静态复核确认两个问题关闭。ACK 仅确认 JS 收件，不代表快照有效或设备执行。

原生仅通过已登录账号的 HOME/DEVICE-02 确认归属，再获取 DEVICE-01 连接参数。初次连接参数仅用于确认 thing reference；每次实际连接重新获取凭据，签名、连接参数及 reported 原文均不传 RN。当前有效期编码保留 UNKNOWN，不根据数值大小推断单位；只读 profile 仅采用 V1.6 明确的 ConnectType online/offline，没有默认写入能力。

iOS 已同步 major2 方法、投递确认及安全不可用摘要、Shadow 请求快照标志；不存在已实现 broker 的假象。静态工程检查为187个对象、43份App源码、13份XCTest源码和148项测试方法定义。尚未执行 Swift/ObjC++ 编译、XCTest、CocoaPods、iOS Codegen、运行或视觉验收。

Android 实际原生 MQTT、内置 RN 新版页面、完整视觉和首次进入 ANR 必须以新安装包及其模拟器报告另行判定。Node 的真实 MQTT 探测及这些离线测试均不能替代该结果。
