# 自解绑确认与授权隔离

本批同步实现 Android、iOS 与 RN 的 S096 入口，保留真实关系变更联调阻塞。用户已明确暂无第二测试账号和可恢复隔离设备，不执行真实解绑、成员移除或分享绑定。

## 实现

- RN 更多页经版本化宿主契约请求原生确认；真正的执行意图仅由原生确认产生。桥接 major 3，新增三个方法，共 16 个，现有事件及 ACK 契约保持原语义。
- 取消只关闭准备或确认阶段；不能撤销已经发送的任务。异常、超时和未知结果分别处理，不自动重放 DELETE。暂停、页面关闭、账号切换与迟到结果均受会话及页面归属约束。
- 解绑确认后，旧关系观察者的权限和缓存失效，重新执行 HOME-01 与 DEVICE-02 授权；旧请求不能借用后续新授权返回结果。普通重开页面不被误判为重新绑定；显式新绑定与旧关系分离。
- 原生任务持有权威状态。RN 展示确认、取消、执行中、未知、已解除及历史状态；不持有独立登录态或生产 HTTP 客户端。
