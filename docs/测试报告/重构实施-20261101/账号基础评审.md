# 账号基础实现评审与回归

日期：2026-11-01。范围：已实现的账号、HTTP、安全存储及最小宿主上下文；不涵盖尚未实现的整体业务。

独立只读审查发现两项问题：Android 分别读取 session 与 revision 造成非原子上下文；并发 refresh 仅串行执行，仍会重复刷新并可能对切换后的账号发起旧操作。

处理：改为发布不可变 AccountContext；请求、退出、刷新及桥接读取同一快照。刷新在等待锁前捕获调用上下文，拒绝跨账号修订，已完成的重叠刷新不再重复发送。

回归先复现两个失败：并发刷新重复请求、排队中的旧刷新触及新账号。修复后 6 项 Android 单元测试通过，包含迟到登录、迟到退出、失败恢复与上述并发用例。独立窄范围复核未发现这两项修复中的遗留重要问题；审查代理未自行重跑测试，实际命令由主执行者运行。

iOS 使用 MainActor 与共享刷新任务；本次静态审查未识别同类快照问题。尚未在 macOS/Xcode 编译或执行，不能据此认定双端运行一致性通过。
