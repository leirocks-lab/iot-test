# 李P1真实接入开发说明

日期：2026-10-11；范围36条及最小依赖；实施依据CHG-20261011-001。

## 当前接入

- Runtime真实HTTP使用RealHttpClient，平台/IOT模块根分别配置，不推断网关前缀。请求路径由内部/api/app映射/app-api，租户由后端提供；缺配置明确失败。
- 真实Android/iOS设备模式加载0822原生BLE；Mock模式继续原Mock，Web真实BLE不可用。新模块需使用重新构建的开发包。
- 帮助读取返回集合，所有条目保留。设备/首页仅保留实际元数据，缺产品不制造能力，未分房为null；调用方已做必要空值兼容。
- MQTT为可创建的WSS传输准备层，实际Shadow/thing Topic、身份和模型尚未接线；不能据此认为设备控制完成。
- CHG-20261011-002补昵称/所属房间：DeviceSettingsFlow提供独立资源/草稿/保存/核对/刷新状态，More供UI同事接线；房间选择后显式保存，结果未知先读详情/归属，写成功后刷新失败只读重试。成员失败不阻断P1，Home/Device返回时重读元数据。真实未分房GET省略data按文档归一id:null，不接受未说明的空对象或非法候选ID。仅REQ-084/085，规范0.5.0；真实验收仍待账号/租户。

## 公共构建配置

```dotenv
APP_ENV=development
ROWAN_HTTP_MODE=real
ROWAN_DEVICE_MODE=real
ROWAN_APP_API_BASE_URL=https://实际平台模块根
ROWAN_IOT_API_BASE_URL=https://实际物联网模块根
ROWAN_TENANT_ID=后端提供的整数编号
```

上面是字段示意，未配置可用环境；默认.env.example仍Mock。不要在模块根重复加/app-api。当前部署只提供HTTP文档入口，HTTPS或开发HTTP例外尚待确认，当前代码保留HTTPS要求。没有推断租户1或使用Swagger默认Token。

会话按模块根及租户隔离，Mock数据库/会话命名不改。此配置不包含测试账号密码、AccessToken、MQTT密码或设备Key。

## 原生编译

新增react-native-ble-plx 3.5.1/plugin、buffer 6.0.3及纯JS mqtt 5.16.0，通过Expo install安装。Android已以SDK57/RN0.86.3/JDK17/arm64编译成功，开发APK在生成目录及.codex-tmp/artifacts保留，未安装；iOS仅JS导出，原生构建待Mac。

SDK/API核对：[Expo57](https://docs.expo.dev/versions/v57.0.0/)、[BLE官方说明](https://github.com/dotintent/react-native-ble-plx)、[MQTT.js](https://github.com/mqttjs/MQTT.js)。软件编译不替代真实广播布局、CRC向量/0x8F/MTU和实际设备验证。
