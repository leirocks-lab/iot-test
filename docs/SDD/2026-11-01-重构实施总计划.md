## 3. UI、接口及 Android 模拟器验证

### UI

建立范围内页面与状态清单，覆盖正常、加载、空态、错误、离线、禁用、弹窗、键盘及操作中状态。固定参考图版本、设备尺寸、系统字号、语言和测试数据，记录截图、布局/间距/字体/颜色/资源、安全区、滚动、导航及触摸检查结果。小屏、大屏和字体缩放分别验证。

原生与 RN 页面都需比对；本地设计图缺失、蓝湖不可访问或版本未核实时记录待核对，不臆造参数。Android 截图不能证明 iOS 视觉通过。

### HTTP 与 MQTT

HTTP 逐接口核验请求参数、认证、数据映射、错误提示、分页及业务结果，覆盖失效会话、权限不足、空数据、超时和适用的重复操作。MQTT 核验凭证、连接、订阅、快照、上报、命令确认、重连及首页/RN 状态一致性，区分发送、云端接受和设备执行。

实际测试服务与测试替身分开记录。缺接口、服务异常、缺凭据或协议冲突列为阻塞，不使用固定数据伪装成功。发送验证码、注册、解绑、删除、升级等有业务副作用的测试使用明确测试对象和专门用例，不能由通用探测脚本自动执行。

### 模拟器

以 `ROWAN_API_36` 为基础，补充小屏、大屏和字体缩放配置。安装正式 Android 宿主，验证原生/RN 页面、返回栈、权限、前后台、切账号、网络异常和真实 HTTP/MQTT 链路。Release 必须验证脱离 Metro 的启动及内置资源加载。

BLE 配网、真实扫码、设备执行和实际固件升级只完成可模拟部分；真实手机/模组项目本轮单列未验收，不作为模拟器阶段关闭条件，也不能计为真实闭环通过。

## 4. 代码与交付门槛

遵循根及各工程 AGENTS.md 和代码规范；HTTP、MQTT、BLE 独立封装，页面不散落通信、存储或 SDK 调用。原生统一管理凭据、权威状态、连接和任务，RN 只保留展示状态。共同契约同步 TS/Kotlin/Swift，覆盖版本、权限、快照/事件竞态、超时、取消、释放和旧会话隔离。

新 RN 使用自身锁文件、lint、typecheck、相关测试及双平台 Bundle；原生分别完成静态检查、测试和构建。修改旧工程时运行其 lint/typecheck 及受影响检查。构建工具链经实际集成结果验证后冻结，当前候选 RN/React 为 0.86.3/19.2.3。

缺少 macOS/Xcode 时保留 iOS 构建和运行未验证状态；Android 继续推进。所有依赖、锁文件、正式工程、构建入口和非秘密配置交付，凭据不写入源码、报告或安装包配置。
