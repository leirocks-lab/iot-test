# 设备更多只读桥接契约

当前宿主契约已修订为[major3](原生页面关闭与桥接V3.md)，下列只读方法/DTO沿用最初major2设计，关闭原生页面必须使用本页初始令牌；旧V2运行证据不证明V3新包。

本批继续实现既有范围中的S084–S086、S090及设备版本/房间信息。业务依据与精确HTTP来源见[核对记录](设备更多与分享契约核对.md)。当前为实施契约，不代表接线或运行已通过；昵称保存、房间选择修改、成员移除、自解绑及分享生成/消费另以专用副作用契约实现，不能用本批GET替代完整范围交付。

## major2方法与安全摘要

四方法均接受当前原生页面持有的`observationId:string`，不得接受任意deviceID、userID或HTTP路径。

| 方法 | Promise结果 | 必需字段（全部string） |
| --- | --- | --- |
| getDeviceMoreSummary | DeviceMoreSummary | deviceNickname、deviceName、productName、productCategory、seriesName、modelName、mcuVersion、wifiVersion、bindingRole |
| getDeviceMembers | DeviceMemberSummary数组 | itemKey、nickname、bindingRole |
| getDeviceHelp | DeviceHelpArticle数组 | itemKey、title、content、createdAt |
| getDeviceLocation | DeviceLocationSummary | assignment、roomName |

缺失文本用空串表示，UI使用未提供的通用文案，不造设备名、成员昵称或版本。bindingRole只取sa/mbr/obs/unknown；不从未知角色推导写权限。成员计数只统计已识别sa+mbr，观察员单列；存在unknown时提示只计入已识别关系，不假设总人数。

itemKey仅本地展示，不使用真实ID、ID哈希或联系人字段，不代表后续写操作许可。原生成员关系及文章标识留在原生；本批不提供删除、生成二维码或消耗分享凭据的方法。summary的版本来自DEVICE-02元数据，不能证明当前设备在线、升级状态或候选可用性。

帮助固定请求`type=text`，正文作为普通文本，不执行HTML、不自动打开链接。摘要不添加MAC、邮箱、手机、userID、bindCode、Token、原始JSON或任意URL字段。

assignment仅assigned/unassigned/unknown。只有经过明确契约确认的未分配响应才能产生unassigned；当前ROOM-02缺失/null数据只投影unknown，不等同“未分配”。合法房间ID证明assigned，roomName独立可未知；错误类型应报固定错误，不强行解析成空态。

## 原生服务与生命周期

每方法fresh核验当前账号修订、HOME归属及DEVICE-02身份，然后调用独立HTTP仓库，并将同一意图expectedRevision传入账号请求边界；结果返回前再次核验账号、设备观察和页面。RN不提供认证材料，不创建第二套通信或存储。

原生复用既有DeviceRoomRepository读取归属；补路径完整`.`/`..`拒绝且保留其他opaque ID，不在更多页面复制ROOM协议。HTTP、成员、帮助及设备摘要解析集中在仓库，不散落在页面。

沿用只读桥接任务的最多2个原生在途、协作式超时、实际Job完成后释放名额、模块失效关闭门、取消终结一次与迟到结果守卫。RN沿用单在途加一个最新目的地，按页面、kind、账号及观察代次隔离，后台和离页清除可见私有数据。现有定时/固件入口复用同一观察，不重新争抢设备会话。
