## 全局约束

- 分支精确命名为 refactor，用户指定优先于默认分支前缀。
- 保留 docs 原始资料与唯一业务范围表，不修改 xlsx。
- 保留用户原有 .gitignore 未提交修改。
- 不将本机 Expo 生成目录当成正式原生工程。
- 本次不创建原生应用、不删减现有 RN 业务功能、不提交或推送 Git。
- 本机依赖和缓存不纳入版本管理，迁移后重新校验工具执行路径。

## 检查重点

- 所有原有受版本控制的应用源码与资源均保留在 app-rn，除路径相关配置外不改变内容。
- 私钥、环境配置、依赖与生成工程继续忽略，公开开发证书保持可跟踪。
- 原有 docs 指向源码的链接随迁移修正，历史结论和验收状态不改写。
- 工具报告仍写入根 docs，不另建 app-rn/docs。
- 根编辑器设置及 RN 格式化命令从新目录定位正确配置。
