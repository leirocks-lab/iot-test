# 设备只读功能桥接契约

当前关闭接口升级为[major3原生页面令牌契约](原生页面关闭与桥接V3.md)。本文保留只读字段的major2设计来源；原有V2测试与截图不作为V3运行通过依据。

这是major2集成阶段的扩展契约。Android服务、桥接与RN页面已接线，33个套件共354项JVM测试及77项RN测试通过。新Release真实定时空列表与返回通过，两类固件返回null而契约未定义该状态，候选读取阻塞；iOS签名已同步但缺运行验证。完整证据见[批次报告](../测试报告/重构实施-20261101/定时与固件只读验证.md)。既有观察、ACK及账号隔离保持，各端分别报告。

## 方法与数据

| 方法 | 参数 | 结果 |
| --- | --- | --- |
| getDeviceSchedules | observationId | DeviceScheduleSummary数组 |
| getDeviceFirmware | observationId、kind=mcu/wifi | DeviceFirmwareOffer |

DeviceScheduleSummary仅含：itemKey、name、type、startTime、repeatType、weekdays数字数组、timeZone、nextExecutionAt、enabledState。type/repeatType采用已识别业务枚举或unknown；enabledState为enabled/disabled/unknown。nextExecutionAt只能来自服务端，不由App推算。itemKey为当前观察下的本地展示键，不作为后续写操作授权。

DeviceFirmwareOffer仅含kind、version、remark、deviceName。它是可用固件信息，不推导hasUpdate、当前设备版本、百分比、升级阶段或可取消性。没有生产升级许可与持久任务管理时不开放启动/取消。

不传原始HTTP/MQTT JSON、日程action/mode字典、Token、broker连接参数、MAC、bindCode或任意URL。没有确认的产品模型版本时，日程读取保留unknown，不填假版本；创建动作仍必须取得产品原生许可。

## 原生守卫与生命周期

- 参数只引用当前Native DeviceActivity/DeviceViewController所持观察句柄；核验设备及账号修订，RN不能仅凭任意deviceID取得访问。
- 原生通过当前账号校验设备归属，再调用各自HTTP仓库；请求传同一次账号上下文核验的expectedRevision。服务端仍做最终权限判断。
- 异步返回前重新核验观察和页面；释放/切账号后不返回旧数据。每个观察的在途调用数量有上限，离栈和module销毁取消本地等待。
- Android当前每观察最多2个原生在途调用，协作式取消超时为15秒；底层阻塞HTTP会受连接/读取超时约束，取消可能等待IO结束，因此15秒不是硬性返回期限。取消期间仍占用原生在途位置，避免重试扩大实际并发。这些是本地资源限制，不是后端SLA。RN控制器单在途并最多保留一个最新目的地，快速切换固件种类时不并发叠加读取；迟到结果不更新已离开的页面。
- 方法仅GET；不生成分享码、不创建/启停/删除日程、不创建或取消升级。后续副作用命令必须另有明确契约、权限及未知结果处理，不能通过字符串RPC直通SDK/HTTP。
- 错误只输出固定代码与用户可理解的通用文案；后台错误原文、路径和认证材料不传RN。

## RN展示与证据

页面处理加载、空数据、错误、重试和返回；取消与迟到结果按当前页面及观察隔离。无动作映射时不把raw action转换为可写控制。时区/下次执行展示不改变云端时间语义。

真实只读接口验证与UI视觉结果分别记录；测试替身只覆盖可控状态。iOS编译与运行受工具链限制时保留未验收，不能用Android结果替代。
