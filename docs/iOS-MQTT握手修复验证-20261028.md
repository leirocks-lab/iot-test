## 问题与修复

iPhone XR / iOS 18.7.11 上 WebSocket 握手返回 HTTP 403。相同凭证、签名与 mqtt 子协议，不带默认端口的 URL 握手成功并收到 CONNACK（返回码 0）；加上 `:443` 则返回 403。MQTT.js 5.16.0 重建 URL 时补入默认端口，iOS SocketRocket 将其保留在 Host 请求头，与签名使用的无端口 Host 不一致。

`src/protocol/mqtt-browser.ts` 仅在 iOS 且凭证包含 sessionToken 时，通过 transformWsUrl 返回原始签名 URL。Android、Web 及旧七字段认证不增加该选项。不修改原生工程、依赖或后端配置。
