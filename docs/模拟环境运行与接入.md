# ROWAN 模拟环境运行与接入

默认开发、预览使用HTTP与设备Mock。本文为历史模拟环境说明，当前通信方式见根目录 README。

```powershell
pnpm install
pnpm web
# 原生开发构建使用 pnpm dev
```

示例账号 `rowan@example.com`，密码 `Rowan@123`，开发验证码 `123456`。添加产品选择除湿机后扫描模拟蓝牙广播；填写非空Wi-Fi名称、密码即可模拟2.4GHz配网。模拟频段、密码错误通过“我的→开发工具”注入，并非无线硬件验证。

开发工具提供HTTP和设备故障、重置数据。Mock数据库原生写入应用文档目录；会话使用SecureStore。Web数据库使用localStorage，会话仅在内存中，浏览器刷新后可重新登录；业务数据继续保留。重置使用新generation隔离旧账号偏好。

```powershell
pnpm lint
pnpm typecheck
pnpm test
pnpm run doctor
pnpm verify:config
pnpm export:android
pnpm export:ios
```

生产配置必须 `APP_ENV=production`、两类模式均为 `real`，并设置HTTPS的 `ROWAN_APP_API_BASE_URL`。缺少真实驱动时明确报错；不自动回退Mock，不将此配置验证视为上线许可。

真实接入在 `src/services/runtime.ts` 组合适配器：HTTP共用 `HttpClient`，设备驱动实现 `DeviceTransport` 并注入 `createRuntime`。保持业务服务和页面接口；真实契约差异、固件G项在适配层与版本化profile中解决。接入后运行相同契约测试、双平台运行回归及设备验收。

Classic Shadow的desired accepted仅表示云端接收，设备reported回报才确认控制值。AT和55AA模拟执行信封是测试边界，不是实际UART驱动。Mock云日程在本地进程运行，不能证明App关闭后的真实云端执行。
