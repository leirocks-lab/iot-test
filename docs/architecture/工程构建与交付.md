## 工程与工具链

| 工程 | 当前配置 |
| --- | --- |
| RN | React 19.2.3、RN 0.86.3、TypeScript 6.0.3、pnpm 11.19.0、Node ≥22.13.0 |
| Android | Kotlin 2.1.20、compile/target SDK 36、min SDK 24、NDK 27.1.12297006、Hermes |
| iOS | Rowan Xcode 工程、CocoaPods 配置、Swift 与 Objective-C++ 桥接；实际 macOS 解析和编译待验证 |

RN 使用自身 pnpm-lock.yaml，Android 提交 Gradle 依赖锁；iOS Podfile.lock 应在真实 macOS 解析后生成，不能手写冒充。完整版本以各工程配置及锁文件为准。

## 构建路径

```text
app-rn 源码与 specs
 → 平台 Codegen 与原生实现
 → Android / iOS Bundle 和资源
 → 对应原生宿主安装包
```

Android [build.gradle](../../android-as/app/build.gradle) 显式引用 `../app-rn`；iOS [Podfile](../../ios-as/Podfile) 从同一目录解析依赖。入口为 `app-rn/index.ts`。正式宿主不由 Expo prebuild 管理。

## 命令与前提

以下从仓库根执行；先安装锁定依赖、SDK 并提供非秘密环境配置。编译成功与签名分发分别验证。

```bash
pnpm --dir app-rn install --frozen-lockfile
pnpm --dir app-rn lint
pnpm --dir app-rn typecheck
pnpm --dir app-rn test
pnpm --dir app-rn bundle:android
pnpm --dir app-rn bundle:ios
(cd android-as && ./gradlew :app:assembleDevelopmentDebug)
(cd android-as && ./gradlew :app:assemblePreviewRelease)
(cd android-as && ./gradlew :app:bundleProductionRelease)
```

RN 独立 bundle 脚本用于资源生成，不替代宿主安装包验证。iOS 依共享 Scheme 在 macOS 完成 Pods 解析、Codegen、编译、测试及 Archive；签名与 Export 配置就绪后再记录可复现分发命令。

## 环境与产物

| 环境 | 应用标识 | Android 典型变体 | iOS Scheme |
| --- | --- | --- | --- |
| development | com.rowan.iot.dev | developmentDebug | RowanDevelopment |
| preview | com.rowan.iot.preview | previewRelease | RowanPreview |
| production | com.rowan.iot | productionRelease | Rowan |

development 可使用 `.dev.refactor` 隔离验证身份。当前 development 绑定调试签名，预览和生产签名须通过受控配置提供，不把可编译等同于可分发。

- 原生归档名：`rowan-{platform}-{environment}-{appVersion}-{buildNumber}-{gitSha8}`，保留真实 apk/aab/ipa/xcarchive 格式。
- RN 资源规划名：`rowan-device-{platform}-{environment}-{bundleVersion}-bridge{bridgeMajor}-{gitSha8}.zip`；归档、签名及发布治理未完整落地。
- 每次交付关联完整 Commit、锁文件、构建号、平台、桥接版本、资源 Hash 和实际测试环境。

Release 必须验证包内资源可离线启动，不依赖 Metro。RN ZIP 不是安装包，不同平台和运行时产物不能互换。现有脚本见 [Android](../../android-as/scripts/build.mjs)、[RN](../../app-rn/scripts/bundle.mjs)、[iOS 结构检查](../../ios-as/Scripts/verify_project.py)。
