# 安全与数据管理

[返回架构总览](架构总览.md)

## 信任与授权

原生账号服务持有身份，服务端负责最终授权。RN props、角色展示字段、能力版本及 observationId 均不能单独作为操作许可。

桥接按真实账号修订、观察句柄、设备授权及当前页面校验请求。解绑由原生确认并生成自身操作上下文，RN 不传用户设备关系凭据。

## 存储与数据边界

| 数据 | 当前位置或约束 |
| --- | --- |
| 登录会话 | Android AES-GCM 加密后写入私有 preferences，密钥留在 AndroidKeyStore |
| iOS 登录会话 | Keychain，首次解锁后仅本机访问，适配器在私有串行队列执行 |
| 解绑及昵称恢复记录 | 原生加密或 Keychain 日志，按账号和操作上下文恢复 |
| MQTT 凭据 | 原生通信层使用，不进入 RN DTO 或公开日志 |
| Wi-Fi 密码 | 配网目标由原生短期使用，不进入 RN 页面或持久日志 |
| RN 展示副本 | 页面内存；不是设备、权限或云端业务记录的最终权威 |

源码入口：[Android 会话存储](../../android-as/app/src/main/kotlin/com/rowan/iot/data/storage/SecureSessionStorage.kt)、[iOS 会话存储](../../ios-as/Rowan/Data/Storage/KeychainSessionStorage.swift)。

## 隔离与清理

- 账号切换推进 sessionRevision，使旧结果和资源授权失效。
- 释放自身观察，不借助其他页面的连接或关闭令牌。
- 安全存储写入与退出竞争时，由账号服务处理迟到写入和清理结果。
- 原生协议数据经明确 DTO 投影后跨桥，不透传 SDK 对象、原始凭据或任意请求入口。
- 设备离线或摘要过期时保留 stale 标记，不从缓存推导操作许可。

## 网络与日志

预览和生产要求 HTTPS；development 的 HTTP 例外仅用于受控联调。禁止为联调关闭生产证书校验。HTTP 重定向、服务地址和响应校验集中在客户端适配层。

Token、密码、设备密钥、签名 URL、证书私钥和签名密码不提交仓库。日志仅保留脱敏错误类别及必要关联信息；真实服务响应和抓包按受控证据管理。

## 资源更新边界

当前默认使用包内 RN 资源。远程更新属于另行授权能力；若实施，须在执行前完成可信签名、兼容、大小与路径校验，并提供原子激活和回滚。Hash 只证明内容一致，不能证明来源可信。设备固件 OTA 与 RN 资源更新分别管理。
