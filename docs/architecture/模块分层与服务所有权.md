# 模块分层与服务所有权

[返回架构总览](架构总览.md)

## 模块与依赖

| 模块 | 职责 | 依赖边界 |
| --- | --- | --- |
| Features / Navigation | 原生页面、交互与全局导航 | 调用领域服务，不直接操作 MQTT SDK |
| Domain | 账号、设备、房间、定时、OTA 等业务规则 | 通过接口使用外部能力，不依赖页面或 RN |
| Data / Platform | HTTP、MQTT、存储、扫码及系统能力 | 实现领域接口，隔离 SDK 类型 |
| Bridge | 权限守卫、DTO 转换、事件投递 | 调用同一原生服务，不复制业务状态机 |
| RNHost | RN 页面挂载、参数和生命周期 | 不拥有账号与设备协议状态 |
| RN entry / features | 设备内部导航与展示 | 通过 host/adapter 调用宿主 |
| RN host/specs / adapter | Codegen 规格、展示校验及观察控制 | 不持有生产连接和长期凭据 |

当前 Android 为单一 app 模块，iOS 为 Rowan Target；分层主要由目录和接口约束，不代表已拆成独立库。RN 的 application、products 等目录部分仍为预留结构，实际入口直接编排控制器。

## 服务装配

Android 在 [AppServices](../../android-as/app/src/main/kotlin/com/rowan/iot/app/AppServices.kt) 装配依赖，iOS 在 [RowanAppServices](../../ios-as/Rowan/App/RowanAppServices.swift) 装配。设备服务延迟创建，账号启动不应被 MQTT 初始化阻塞。

原生页面和 RN 桥接复用这些服务。Android 以协程作用域管理工作，iOS 按 MainActor 和适配器队列隔离状态；网络和存储不得阻塞 UI。

## 所有权与释放

| 资源 | 所有者 | 释放或失效条件 |
| --- | --- | --- |
| 账号与登录态 | AccountService | 退出、会话失效或切换账号 |
| 设备权威读取状态 | DeviceReadOwner | 原生策略回收、撤权或账号失效 |
| MQTT 连接与订阅 | SharedBrokerPool | 结合租约、订阅引用和账号有效性回收 |
| 页面观察句柄 | Bridge 与页面控制器 | 卸载、释放观察或原生生命周期兜底 |
| 解绑操作及恢复日志 | 原生 SelfUnbindApplication | 按真实操作结果完成清理和恢复 |
| RN 路由、输入和展示副本 | 当前 RN 页面 | 退出页面或上下文变化 |
| RN runtime | 原生宿主 | 按容器策略管理，不等同于设备连接寿命 |

## 设计约束

- RN 退出只释放自身观察，不直接关闭其他使用者的设备连接。
- 长期任务与页面分离；取消等待不代表撤销已经派发的操作。
- 账号修订变化后，旧授权、回调和资源关联失效。
- 完整 OTA 任务恢复、配网和控制写入仍须按[业务流程](核心业务流程与状态机.md)完成接入。
