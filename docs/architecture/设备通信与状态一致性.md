# 设备通信与状态一致性

[返回架构总览](架构总览.md)

## 通信边界

| 通道 | 职责 | 当前接入 |
| --- | --- | --- |
| HTTP | 账号、设备授权、目录、房间及设备业务接口 | 原生 Client 与 Repository |
| MQTT | 影子状态读取和连接恢复；控制为目标能力 | 原生读取 Owner 与共享连接池 |
| BLE | 发现和配网 | 双端正式目录仍为空占位 |

Android HTTP 通过 `RowanHttpClient`，iOS 通过 `RowanHTTPClient`；Repository 解码业务响应。客户端集中处理地址、认证、超时和响应封装，页面不选择服务地址。

## 设备读取链路

```text
原生或 RN 观察请求
 → DeviceReadOwner
 → HTTP 授权与设备元资料
 → AuthorizedDeviceConnections
 → SharedBrokerPool
 → MQTT 订阅与影子 get
 → Shadow Reducer
 → 原生状态摘要
 → 原生页面与 RN 展示
```

Android 使用 Paho；iOS Podfile 声明 CocoaMQTT/WebSockets，实际 SDK 与 Xcode 集成尚待验证。业务设备 ID 与 MQTT thingRef 分开保留，不默认相等。

Owner 按账号和资源管理读取状态，连接池按连接身份复用传输并维护订阅引用。重新连接后通过新的连接代际和快照恢复，不能把旧缓存标成实时在线。

## 一致性规则

| 场景 | 处理规则 |
| --- | --- |
| 首次观察 | 订阅先于快照应用，处理 Promise 与事件交错 |
| 重复或迟到结果 | 比较观察、会话、代际及修订，拒绝过期数据 |
| 事件缺序或溢出 | 有界缓存，读取原子快照重同步 |
| 断线 | 标记 stale / recovering，保留值不等于实时有效 |
| 切账号或撤权 | 终止旧观察，失效授权、连接及迟到回调 |
| 页面退出 | 释放自身租约与监听，由原生决定共享资源回收 |

设备读取阶段为 authorizing、connecting、reading、live、recovering、failed、closed。在线值为 online、offline、unknown，unknown 不得转换为离线。

## 控制目标与未决项

控制目标链路为“校验权限和已发布物模型 → desired 下发 → 云端接受 → 设备 reported → 确认结果”。publish、PUBACK 和 desired accepted 均不等于设备执行成功；未知结果不得自动重放写操作。

当前原生装配的读取 profile 不含完整可写产品映射，桥接尚无正式控制命令。凭据 README 已记录 expiresAt 为 epochSeconds，但服务装配仍使用 UNKNOWN，需要统一核对；iOS Host 策略也仍标为 unknown。

Topic、报文和产品能力细节见 [MQTT 专题](MQTT架构与流程.md)、[物模型专题](物模型架构与流程.md)和[原生接入核对](../SDD/MQTT原生接入核对.md)。其中目标控制流程不代表已完成运行验收。
